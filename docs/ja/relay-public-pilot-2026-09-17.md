# パブリック WSS パイロット — 2026-09-17

ユーザー承認済みの KR での一時的パイロットであり、完了後に削除されました。これは制限された統合チェックであり、本番デプロイや持続的な運用結果ではありません。

## 経路と隔離

Mac クライアント → パブリック Cloudflare HTTPS/WSS → KR Caddy の正確なテスト用ホスト名 → 127.0.0.1:3769 ブラインドリレー → 認証済みレシーバー → 既存の Antigravity ブリッジ。アプリケーションの TLS 1.3 チャネルは WebSocket の内部でデバイス証明書をピン留めします。パブリック TLS 終端がアプリケーションの平文を受信することはありません。ネイティブアクセスは、明示的に許可された 1 つのピアと既存の `agy-kr` セッションエイリアスに限定されました。

以前の SSH ポート転送プロセスは、テスト前に停止されました。パブリック宛先ルーティングには Tailscale インターフェースではなく、en1 / ローカルインターネットゲートウェイが使用されました。SSH は管理および読み取り専用のトランスクリプト確認のために個別に使用されました。これは VPN を無効にしたスマートフォンでのテストや、生の TCP NAT トラバーサルを実証するものではありません。

リレーは DynamicUser、ProtectHome、ProtectSystem=strict、NoNewPrivileges、256 MiB メモリ、50% CPU、64 タスク、10 接続のアプリケーション制限、および 30 分の実行時間上限で実行されました。Caddy の変更前に、独立した 30 分の systemd クリーンアップタイマーがセットされました。DNS やファイアウォールの変更は行われませんでした。

## 観測結果

- パブリック未認証アドミッション: HTTP 401。
- 認証済みのペアリング `list`: 既存の Antigravity セッションが返された。
- パブリック送信マーカー: `SP090_PUBLIC_e037d3d2d993`。
- リクエスト ID: `e037d3d2-d993-4fae-8c03-dbc66619967c`。
- ネイティブ結果: submitted, `consumptionConfirmed=false`。
- 独立して観測された MODEL トランスクリプト: `ACK_SP090_PUBLIC_e037d3d2d993`。
- 同じリクエスト ID/本文の繰り返し: `duplicate=true` および同じネイティブリクエスト ID を持つ永続化されたレシート。2 回目のネイティブ送信は要求されなかった。

この独立して観測された ACK は、この特定のメッセージに関する証拠を強化します。一般的な送信規約を配信確認に変更したり、クラッシュ時の厳密に 1 回の配信を確立したりするものではありません。

## クリーンアップ

他の設定を保持したまま、正確な一時的 Caddy ブロックが削除されました。検証/リロードは成功しました。Caddy の SHA256 はテスト前の値 `60ae35627b82d65724ceac89421e1f92ba475b675fd146b4036129f352197ebb` に戻りました。パブリックテスト用ホスト名は元の HTTP 301 応答を返しました。リレーサービスは停止され、ループバックポート 3769 は閉じられました。クリーンアップタイマーは、ロールバックが成功した後にのみ解除されました。一時的なレシーバーとネイティブブリッジは停止され、ユーザーの Antigravity TUI は実行されたまま維持されました。テスト用の認証情報と一時的なサービスインストールはその後削除されました。
