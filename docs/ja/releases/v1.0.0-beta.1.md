# session-peer v1.0.0-beta.1

最初の 1.0 ベータ版は、依存関係のないローカルおよび SSH ワークフローを維持しながら、
認証済みリレーを安定した契約へ向けて前進させます。

## ハイライト

- 返信 URI、JSON 結果、リレーと control プロトコル、バックアップ manifest、migration、
  廃止ポリシーに関する v1 互換性契約を凍結します。
- 暗黙的な control データベース初期化を、順序付き transactional なファーストパーティ
  migration と、適用済み schema revision を記録するバックアップ metadata に置き換えます。
- ユーザー、デバイス、token、session、message の識別子なしで、上限付き relay capacity、
  admission 拒否、および rate-limit metric を公開します。
- 受信側のポリシーと所有権チェックを維持しながら、ネイティブ Windows Codex を明示的に
  対象とする WSL relay receiver をサポートします。
- 再利用可能なデプロイ例と運用者専用 artifact を再編成し、source distribution から
  private な運用設定を除外します。

## ベータ版のインストール

Python package manager は通常 prerelease を選択しません。明示的に選択してください:

```bash
pipx install 'session-peer[relay]==1.0.0b1'
# or
uv tool install 'session-peer[relay]==1.0.0b1'
```

ペアリングした両 endpoint で同じ package version を使用してください。core は Python
3.9+ をサポートし、オプションの relay runtime には Unix または WSL と Python 3.11+ が必要です。

- [プロジェクト概要](https://abruption.dev/projects/session-peer/)
- [ペアリングデバイスガイド](https://github.com/abruption/session-peer/blob/v1.0.0-beta.1/docs/paired-devices.md)
- [v1 互換性契約](https://github.com/abruption/session-peer/blob/v1.0.0-beta.1/docs/compatibility-v1.md)
- [セキュリティポリシー](https://github.com/abruption/session-peer/blob/v1.0.0-beta.1/SECURITY.md)

## ベータ版の境界

- 明示的な tester 向けの prerelease です。通常の stable upgrade は引き続き v0.9.1 を
  選択します。
- ホスト型 relay の可用性と OAuth provider ポリシーは、package 公開とは別の運用
  service のままです。
- WSL サポートはネイティブ Windows Codex を対象とする Unix relay receiver を扱い、
  receiver とオプションの relay runtime は Windows 上でネイティブ実行されません。
- Control migration は forward-only です。upgrade または rollback の前に persistent
  state を backup し、文書化された互換性契約に従ってください。
- Pairing と OAuth だけで native agent へのアクセス権は付与されません。受信 endpoint は
  引き続き local policy を適用し、ユーザーは実際の agent 結果を確認します。

バグは GitHub issue、セキュリティ問題はリポジトリの private advisory channel に報告してください。
報告には token、device key、certificate、session ID、conversation content を含めないでください。
