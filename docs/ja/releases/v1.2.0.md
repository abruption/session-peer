# v1.2.0リリース候補

## 範囲

公開版1.1.2を基に2026-10-15に準備しました。候補は未公開で、2026-10-18のマイルストーン目標は公開の約束ではありません。この準備ブランチはバージョンと文書のみを変更します。次の提案は別PRのマージと統合検査の成功後に初めてリリースに含まれます。

## 提案する変更

- PR #311：追加の設定レイヤーにある既知のCodex保存先変更を拒否し、作用前にqueue実行計画を検査します。共有daemonの経路選択はnativeに任せ、検査成功を実効保存先の証明としません。
- PR #310：Codexの対象世代は未対応のままとし、否定的な証拠のテストを追加します。writerロック、queue ID、turn IDは元の世代の原子的な一致を証明しません。
- PR #314：危険・古いチャネル、保持期間、明示的な復元履歴の隔離、collector再起動時の確定済みACK分類保持をオフラインでテストします。新しいランタイム対応は追加しません。
- PR #305：macOS/Linux Antigravity 1.3.3の登録後の限定的検証を保存します。Antigravityは安定版対応ではなく実験的機能のままです。
- PR #313：2026-10-13のmacOS起動・受信側bridgeの過去の証拠を保存し、ownerの受信と呼び出し側実行、出所の限界を区別します。
- PR #308：隔離したCodex初回入力probeを強化します。サーバー履歴を確認できない場合は安全側に拒否するため、未保存の空TUIは拒否される場合があります。26件の回帰テストには未対応API例を含み、一般的な初回入力対応の証拠ではありません。

## 検証と残る条件

最新コミットのレビュー・CI、順次統合、単独ファイル再生成、翻訳ハッシュ、全プラットフォームテスト、隔離wheel/sdistインストールと最新の依存関係監査が必要です。各ブランチの成功は最終統合ツリーの証拠ではありません。全マージ後の正確なmain CI成功、不変ドラフト資産7個と証明の確認、必須の人手によるpypi環境承認が必要です。準備はマージ、タグ・ドラフト作成、ワークフロー実行、公開、配備の承認ではありません。

Issue #180、#181、#268、#304、#306、#307は未完了のままです。native Codex世代・ACK、完全な保存先検証、一般的な空TUI入力、Antigravity安定版対応、残るnative・プラットフォーム受け入れ条件は提供しません。固定handoff契約とfixtureは変更しません。submitted/queuedは消費やACKではなく、unknownは自動再送を許可しません。

プラグインと別管理スキルのバージョンは独立し変更しません。新しい実SSH、Relay、MCP、OAuth、フリート、nativeエージェントの受け入れ証拠は主張しません。過去のRC4 ACK証拠は20/21のままで、#161は原因未確定の監視項目です。パッケージ公開に本番配備は含まず、Control/Relay配備と各端末の更新には別途の承認・検証が必要です。
