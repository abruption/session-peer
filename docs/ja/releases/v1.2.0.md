対象6件のPRはマージ済みですが、PR #315には最終コミットのレビュー・CI、単独ファイル再生成の検査、翻訳ハッシュ、全プラットフォームテスト、隔離wheel/sdistインストールと最新の依存関係監査が必要です。各ブランチの成功は最終準備ツリーの証拠ではありません。別途の承認による準備PRのマージ後、正確なmain CI成功、SHA256SUMSとrelease-provenance.jsonを含む不変ドラフト資産7個と証明の確認、必須の人手によるpypi環境承認が必要です。この準備はPR #315のマージ、タグ・ドラフト作成、ワークフロー実行、公開、配備の承認ではありません。
