# v1.5.0 リリース準備

公開済みv1.4.2（[GitHub](https://github.com/abruption/session-peer/releases/tag/v1.4.2)、[PyPI](https://pypi.org/project/session-peer/1.4.2/)）を基に2026-11-09に準備しました。この日付の確認時点でv1.5.0は未公開のソース候補でした。統合ソースの基準は`a622dc0d9f04a252af65147eb36188998bf0c8b4`で、バージョン準備前の値であり最終公開コミットではありません。所有者が依頼したのはこのリリース準備PRまでです。この準備は、準備PRのマージ、タグ・ドラフト作成、ワークフロー実行、公開、運用変更を承認しません。

## 候補の範囲

- #390 / #389は、安定版SDK 1.xの1.30以降を維持し、安定版SDK 2.xの2.3以降を受け入れるMCP SDK互換性を追加します。エクストラは`mcp>=1.30,<3,!=2.0.*,!=2.1.*,!=2.2.*`で、SDK 2.0–2.2、プレリリース、開発版は引き続き除外します。SDK 2.3+では`MCPServer(subscriptions=False)`を使い、サブスクリプション・listen・状態照会・待機のインターフェースは追加しません。公開ツール6個、プロジェクト結果データのスキーマバージョン1、ポリシーバージョン1/2、権限、ホスト承認、結果不明時の扱い、自動再試行の禁止は維持します。SDK 2のPython属性とcamelCaseの通信上の別名を適合させますが、プロトコルバージョン間でSDKのエンベロープまでバイト単位で同一だとは主張しません。
- 依存関係の保守には、#386のGitHub Actions更新、#383のHatchling 1.33.0、#385のVitest 5.1.0、#382のVite 8.3.6と@rolldown/pluginutils 1.0.1を含みます。ビルド・CI・開発用ツールは、外部依存のない基本CLIや稼働中サービスの環境とは区別します。
- #379は、テスト依存のParamiko 5.1.0と対応するテストのアサーションだけを更新します。Paramikoは引き続きテスト専用の依存関係であり、本番SSHの動作は変わりません。
- #381はBetter Auth/core 1.7.18、jose 6.2.15、React/React DOM 19.3.1、tsx 4.23.15を更新し、依存関係の基準と既存のコア契約の検査を含みます。アプリケーションのセッションポリシーとランタイム認証コードは変更しません。上流依存の変更は、実際のOAuthフローや既存の本番データベースとの互換性を検証したという主張ではありません。

## 互換性と検証範囲

基本Python 3.9、任意MCPのPython 3.10、RelayのPython 3.11の下限は維持します。Nodeエンジンは`^22.13.0 || ^24.0.0`、`@types/node`は24、`better-sqlite3`は12.6.2のままです。Controlは非公開バージョン0.1.0を維持し、Python wheel/sdistには含まれません。サービス配備は別の作業です。

ビルド用インタープリターの境界：[Hatchling 1.32.4](https://pypi.org/pypi/hatchling/1.32.4/json)と[Hatchling 1.33.0](https://pypi.org/pypi/hatchling/1.33.0/json)の公開メタデータは、いずれもPython 3.10+を要求します。既存のビルドツールの要件であり、基本ランタイムの下限を新たに引き上げるものではありません。Python 3.9の基本インストールには汎用wheelまたはスタンドアロンの経路を使い、sdistを直接ビルドする場合はPython 3.10+のビルド用インタープリターが必要です。この準備は、Python 3.9によるsdistビルドの検証を主張しません。

MCP候補は、macOS/LinuxのPython 3.10/3.13/3.14で4プロファイル（`minimum`、`latest1`、`minimum2`、`latest2`）を構成し、合計24のCIセルになります。プロファイルごとに解決された版とランタイム依存監査レポートを保存しますが、全推移パッケージの個別の最小版を試験するものではありません。これは検査の構成であり、保留中のCIの成功を主張しません。正確な準備HEADと最終的な保護されたmainコミットでの結果が必要です。クライアント・プロトコル試験と制限は[MCPガイド](../mcp.md#sdk2-compatibility-candidate)を参照してください。

64 KiBの結果制限は上限であり、それより小さいすべての結果を受け付ける保証ではありません。SDK 2は旧プロトコルの接続でも新しいサーバー識別メタデータをサイズ計算に含めるため、上限に近い結果を保守的に拒否する場合があります。プロジェクト内部の結果JSONと、承認・提出・消費・ACKの区別は維持します。新たな実エージェント・SSH・Windows・実OAuth・既存データベースの検証は主張しません。#387/#388と研究Draft #246/#248は今回の範囲外です。
