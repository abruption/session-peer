# v1.1.1メンテナンスリリース

## 範囲

1.1.0を基準に2026-10-12に準備しました。このパッチはドキュメントと開発用テストを保守し、ランタイムの動作は変更しません。[GitHub公開](https://github.com/abruption/session-peer/releases/tag/v1.1.1)と[PyPIファイル](https://pypi.org/pypi/session-peer/1.1.1/json)を個別に確認してください。準備だけでは公開や配備を証明しません。

## 変更点

- #297：開発用SSHテストの依存関係をParamiko 5.0.0に更新し、固定バージョンのテストを修正します。ランタイムSSHは引き続きシステムOpenSSHを使用し、Paramikoは配布するランタイムの依存関係ではありません。
- #281 / #299：4言語のREADME、リリース手順、ドキュメント索引、handoffガイドを公開済み1.1.0の証拠に合わせます。過去のリリースコマンドを保持し、古いバージョン表記を防ぐ回帰テストを追加します。
- 実験的handoffの対応範囲と凍結した契約を変更せず、パッケージとドキュメントのバージョン1.1.1を準備します。

## 検証と既知の制限

公開前に最新の正確なコミットのCI、全ローカルテスト、単独ファイルの再生成、隔離したwheel/sdistのインストール、4言語の検査、最新の依存関係監査を要求します。GitHubの不変アセットと必須の人手によるPyPI環境レビューは別の条件です。これらのドキュメント・テスト変更は、新たな実エージェント、SSH、Relay、各端末の受け入れ検証を証明しません。

#298は未解決です。不正なClaude PID登録ファイルは正常なセッションの探索を妨げ、10進数ではないUnicode数字のセッション名は対象解決に失敗する場合があります。このパッチはそのランタイム不具合を修正しません。

実験的handoffは1.1.0の範囲を維持します。ローカルPOSIX Claudeの受信ACK、相関のみのCodex/SSH送信、未対応の観測・ACK経路は[handoffガイド](../handoff-runtime.md)を参照してください。`posted`/`queued`は消費やACKではなく、不明な結果は自動再送を許可しません。過去のRC4 ACK集計は20/21のままで、#161は未解決です。過去の証拠は新たな1.1.1の受け入れ証拠ではありません。

パッケージ公開に本番環境への配備は含まれません。Control/Relayの配備、各端末のインストール版、ホスティングの可用性は個別に確認する必要があります。このパッチはリポジトリの全脆弱性が解決したことを意味しません。
