# session-peer v0.9.0

既存の Claude/Codex のローカルおよび SSH パスを維持したまま、オプションの Antigravity 配信とペアリングデバイスリレーのベータ版を提供します。

- エージェントアダプターとローカル/SSH トランスポートが、明示的なアイデンティティ、ケーパビリティ、実行、および構造化エラーの規約を共有するようになりました (#47)。
- 認証済みの既存 TUI 内で起動されたオプトインブリッジを介して、Antigravity が受信できるようになりました。登録によってホーム、プロセス世代、スレッドがバインドされます。各ブリッジは有効期限とリクエスト制限によって制限されます (#85)。
- `session-peer[relay]` により、デバイスのペアリング、直接 TCP または WSS 上のピン留めされた内部 TLS 1.3、ピアの失効、ポリシー制限付きのネイティブターゲット、永続的なリクエストレシート、および list/send 向けの `--device` 統合が追加されました (#69)。
- リレーアドミッションは、デバイスのペアリングやネイティブの認可とは分離されています。Linux DynamicUser デプロイメントの例とセットアップ/クリーンアップのランブックが含まれています。
- ペアリングされた `--dry-run` は、メッセージを送信せずにターゲットを解決します。ルートの変更時にも、ピン留めされたピアとレシートジャーナルは保持されます。unknown の結果は自動的に再送信するのではなく、照合する必要があります。
- 英語、韓国語、日本語、簡体字中国語によるコンパクトな README が利用可能になり、クイックスタートとオプション機能の要件が記載されています (#92)。完全な CLI ガイドは `docs/cli-reference.md` に保持されています。詳細な技術ドキュメントは英語のままであり、CLI の出力はローカライズされていません。
- 公開バグ/機能テンプレートと非公開のセキュリティ報告ガイダンスが利用可能になり、代替の非公開連絡先として `support@abruption.dev` が追加されました (#91)。メールは手動で確認され、自動的に Issue として公開されることは決してありません。

## インストールと互換性

コアは引き続きランタイムの依存関係なしで Python 3.9+ をサポートします。オプションのリレーには Unix および Python 3.11+ が必要です: `pipx install 'session-peer[relay]'`。既存のパッケージ管理ユーザーは、それぞれのパッケージマネージャーでアップグレードしてください。スタンドアロンの `install.sh` はオプションのリレーパッケージをインストールしません。

Antigravity はオプトインです。デフォルトの一覧取得には Claude、Codex、およびアクティブに登録されている Antigravity ブリッジが含まれます。ペアリングされたネイティブアクセスには、受信側デバイス上の明示的なポリシーが必要です。ペアリング単体ではネイティブアクセス権は付与されません。デバイス管理コマンドは JSON を出力します。

## 検証と制限事項

ユーザーが承認した一時的なパブリック Cloudflare/Caddy WSS パイロットにより、既存の KR Antigravity セッションへの配信が行われ、独立して観測されたモデル ACK および重複リクエスト時のレシート再利用が確認されました。ルート、サービス、ブリッジ、およびテスト鍵はその後削除され、ユーザーの TUI は実行されたまま維持されました。これは制限された実稼働 Antigravity の証拠であり、実稼働の Claude/Codex や長期的な安定性の証拠ではありません。

送信結果は submitted と consumed を区別します。永続化された意図ジャーナルは重複した自動試行を防止しますが、厳密に 1 回の効果を約束するものではありません。クラッシュにより結果が unknown になる可能性があります。このベータ版には、ホストされたリレー、自動 NAT トラバーサル、自動鍵ローテーション、ジャーナルのガベージコレクション、またはペアリングされた wake/Reply-To ルーティングはありません。運用の制限事項については `docs/paired-devices.md` を参照してください。

v1.0.0-rc の前には、実際のデバイス運用と不具合の解消が引き続き必要です。このリリースによって v1 の安定性が主張されることはありません。
