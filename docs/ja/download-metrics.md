# ダウンロードメトリクス

README の PyPI 月間ダウンロードバッジは、[Pepy](https://pepy.tech/pepy-api) から直接提供されています。クリックすると [session-peer の統計情報](https://pepy.tech/projects/session-peer) が開きます。公開の月間バッジは直近 30 日間をカウントするものであり、暦月やリアルタイムカウンターではありません。Pepy の API ドキュメントによると、公開バッジのエンドポイントは API キーが不要でレート制限もなく、12 時間キャッシュされます。GitHub の画像キャッシュにより表示の更新がさらに遅れる場合があります。バッジは依然として外部依存関係です。

月間: `https://api.pepy.tech/badge/session-peer/month`。
週間: `https://api.pepy.tech/badge/session-peer/week`（直近 7 日間）。

## 解釈

- これらは Pepy による集計値です。公開バッジのドキュメントは、PyPI Stats と同じミラー/CI フィルタリングを確立しているわけではありません。2 つのプロバイダーを混同したり、CI トラフィックが除外されていると主張したりしないでください。ダウンロード測定の制限事項については、[PyPA ガイド](https://packaging.python.org/en/latest/guides/analyzing-pypi-package-downloads/) を参照してください。
- これらのカウントは `session-peer` PyPI パッケージを対象としており、レガシーの `cc-peer`、GitHub クローン、生スクリプトによるインストール、またはすべてのパッケージソースを対象としているわけではありません。
- バッジが利用不可、レート制限中、または unknown であることは、ダウンロード数が 0 であることを意味しません。背景についてはソースリンクを確認してください。README でハードコードされたカウントに置き換えることはありません。

バッジは、既存の README バッジと同様にリモート画像です。これにより CLI のテレメトリや、リポジトリが所有するコレクター、データベース、スケジュールされたワークフローが導入されることはありません。バージョンは変更されず、ドキュメントの更新にリリースは不要です。

## 個別のランディングページ実装

オントロジーセッションがランディングページを所有します。個別にラベル付けされた直近 7 日間および直近 30 日間の PyPI メトリクスには同じ Pepy 公開週間・月間バッジを使用し、ソースおよびプロバイダーのエラー状態を明確に保ちます。これにより、JSON API キーや個別のコレクターが不要になります。公開コードに Pepy JSON API キーを露出させないでください。JSON API アクセスには、公開バッジとは異なる認証、プラン、およびレート制限条件があります。既存のサイト分析は変更されず、この作業によって CLI や訪問者イベントのテレメトリが追加されることはありません。

## プロバイダー変更の検証 (2026-09-18)

オリジナルの Shields.io バッジは PyPI Stats を使用していました。PyPI Stats への直接アクセスで HTTP 429 が返され、元のバッジには以前アップストリームのレート制限エラーが表示されていました。追加の画像キャッシュパラメーターを使用しても、アップストリームへの依存関係は解消されません。curl を使用したところ、両方の Pepy 公開エンドポイントが session-peer に対して HTTP 200 と SVG 数値バッジを返しました（観測時点での丸められたラベルは月間 `2k`、週間 `1k`）。これらの丸められた観測値は README にハードコードされておらず、正確な整数カウントや長期的なサービスの可用性を確立するものではありません。Python の urllib による初期リクエストでは 403 が返されたため、curl の結果をすべてのクライアントに一般化してはなりません。ブラウザと GitHub 画像プロキシの到達可能性は、依然として個別の確認項目です。

## GitHub でのフォローアップ

[GitHub release API](https://docs.github.com/en/rest/releases/releases) は、アップロードされたリリースアセットの累積 `download_count` を公開しています。週間/月間の値を取得するには、日付付きのスナップショットと安定したアセット ID ごとの差分が必要です。ベースラインの欠落、削除または置き換えられたアセット、およびカウンターの減少には、明示的な unknown または連続性の状態が必要です。1 回の累積値から過去の期間を復元することはできません。GitHub アセットのダウンロード数は PyPI とは区別し、クローンや生のスタンドアロンインストーラーのトラフィックとしてラベル付けしないでください。この最初の README の変更では、スナップショットの自動化は実装されていません。
