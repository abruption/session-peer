## Paging limits and evidence

Collection retains at most 4 MiB stdout and 64 KiB stderr, with a 10-second execution budget plus existing, separately bounded owned-process cleanup. These are not a hard wall-clock limit and do not bound all upstream filesystem/SQLite work, escaped remote processes or OS scheduling. Synchronous projection, validation and serialization have no separate elapsed-time deadline and can delay other requests/cancellation. No additional native-version probe, model activation, send or wake is introduced; existing CLI advisory checks and operator-controlled SSH commands remain possible.

The cache permits 4 snapshots, 20,000 rows per snapshot and an 8 MiB serialized charge, not an RSS guarantee. A successfully authorized and formed continuation renews the 30-second idle deadline within an absolute 600-second lifetime. Expired data is pruned lazily; expiry is not a background deletion promise. Cursor/filter/policy mismatch, expiry, eviction or restart refuses without recollection. Keep all filters, including `limit`, unchanged for continuation; the 64 KiB result cap may return fewer rows than requested. A single collection admission slot avoids an unbounded waiting queue. Each full encoded tool result is capped at 64 KiB including text, structured content and conservative SDK 2 metadata, excluding JSON-RPC. Exact IDs are never truncated or merged; optional labels use `nameTruncated=true` or `nameOmitted=true`. Claude IDs are exact decimal strings of native PIDs greater than 1, not generations.

A valid partial page uses `ok=true`, `complete=false` and `isError=false`, retaining permitted rows and continuation. A fixed refusal uses `ok=false`, `type="refusal"`, `isError=true` and `retryAllowed=false`. Completeness describes reported source evidence, not exhaustive native discovery, readiness or later-send safety. Unknown evidence cannot become complete success. Empty partial pages remain incomplete. No automatic retry is allowed; a new explicitly authorized query is separate. See the [MCP contract](../mcp.md#bounded-session-listing-393). Windows refuses this new tool before collection; this is not new Windows native-agent acceptance. Caller identity, consumption, ACK, effective-storage attestation and atomic target-generation guarantees are not added.
