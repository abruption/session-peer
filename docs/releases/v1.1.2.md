# v1.1.2 patch candidate

## Scope

Prepared on 2026-10-13 against published 1.1.1. This candidate is unpublished and addresses #298 only; preparation does not authorize merge, tag creation, publication or deployment.

## Changes

- Bound Claude registry PID parsing before native process inspection and isolate invalid records so healthy sessions remain discoverable.
- Resolve nondecimal Unicode session names such as ² through name matching instead of integer conversion; preserve valid PID addressing and ambiguous-name refusal.
- Apply the same bounded record handling to diagnostics, retain permission diagnostics and regenerate the standalone CLI.
