# session-peer 0.6.1

This release makes cross-agent messages easier to attribute and prevents an
implicit Codex send from silently choosing between duplicate session homes.

## Changes

- Detect duplicate Codex thread UUIDs across the selected/default home, macOS
  Orca account homes, and explicitly configured `SESSION_PEER_CODEX_HOMES`.
  Ambiguous implicit sends fail before queueing; `--codex-home` remains the
  explicit destination selector.
- Add `codexHome`, `submitted`, and `consumptionConfirmed` fields so selection,
  queue submission, and consumption are not conflated.
- Identify detected senders as `claude:<session>` or `codex:<thread-uuid>` in the
  default message envelope and generate a matching reply target.
- Resolve known Tailscale SSH destinations through `tailscale status --json`.
  Online peers route through the current MagicDNS FQDN, offline peers fail before
  SSH, and unmatched destinations remain ordinary SSH hosts.
- Preserve existing SSH config and host keys by keeping the supplied destination
  as the SSH alias, overriding `HostName` with verified MagicDNS, and retaining
  the supplied host through `HostKeyAlias`. Results report canonical `host` and
  original `sshHost` when they differ.
- Organize the standard-library test suite under `tests/` and update CI discovery.

## Compatibility and limits

- Existing Claude/Codex targets, suppression flags, generic SSH destinations,
  and package/standalone install paths remain supported.
- The sender envelope is best-effort metadata, not authenticated identity.
- A queued message is not proof of consumption or acknowledgement. This release
  does not wake sessions, wait for replies, or verify reverse SSH reachability;
  those remain in the v0.7 roadmap.
- Users with more than one Codex home should pass the same explicit
  `--codex-home` to list, dry-run, and send.

## Upgrade

Use the package manager that owns the installation:

```bash
pipx upgrade session-peer
uv tool upgrade session-peer
python -m pip install --upgrade session-peer
```

Standalone installations can run `session-peer update`. Re-run `install.sh` from
the v0.6.1 checkout when the bundled Claude skill should also be refreshed.

## Validation

- 174 unit/integration tests passed with both explicit `tests/` discovery and
  default unittest discovery.
- CI passed on Ubuntu and macOS with Python 3.9/3.13, Windows with Python 3.13,
  package build, standalone install smoke test, shellcheck, and secret scanning.
- Wheel and sdist builds and isolated artifact installs were verified.
- A local Codex list and explicit-home dry-run completed without submission.
- A read-only SSH list supplied by Tailscale IP connected through the verified
  MagicDNS name while preserving the original host-key alias.
