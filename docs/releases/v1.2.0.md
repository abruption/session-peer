# v1.2.0 release candidate

## Scope

Prepared on 2026-10-15 against published 1.1.2. This candidate is unpublished; the 2026-10-18 milestone target is not a publication promise. This preparation branch changes version/documents only. The following proposed changes require their separate PRs to be merged and integration checks to pass before they belong to a release.

Updated on 2026-10-16 during sequential integration. Final-main synchronization, current-head review and combined validation remain pending; no final-main SHA or completed publication is asserted here.

The #311 macOS discovery policy remains metadata-only: standalone list never executes Codex or queries its version, and conservatively checks ordinary as well as forced preferences. This may refuse newer environments whose native loader ignores ordinary values. Send/dry-run uses bounded native-version evidence: only the exact reviewed 0.162.1 selects forced-only checks; older, unavailable or unreviewed evidence includes ordinary values. Physical child cwd and consumer alias checks reduce known configuration ambiguity, not startup-storage or atomic identity uncertainty.

The unexplained Relay exit139 and separate local shutdown diagnostics remain monitored in #316. Passing reruns do not establish a cause, relationship or fix. No test, audit or protection is bypassed.

## Proposed changes

- PR #311: reject known Codex storage relocation in additional configuration layers and check the queue execution plan before effects. Shared-daemon routing remains native; passing checks is not effective-storage attestation.
- PR #310: preserve Codex target-generation unsupported behavior and add negative evidence tests; writer locks, queue IDs and turn IDs do not prove an atomic original generation.
- PR #314: add offline handoff lifecycle tests for unsafe/stale channels, retention, explicit known-restore quarantine and preservation of committed ACK classification across collector restart. This adds no new runtime support.
- PR #305: archive scoped macOS/Linux Antigravity 1.3.3 post-registration validation. Antigravity remains experimental, not stable support.
- PR #313: archive historical 2026-10-13 macOS startup and receiver-bridge evidence, distinguishing owner receipt from caller-side execution and recording provenance limits.
- PR #308: harden the isolated Codex first-input probe. The current server-history guard fails closed when it cannot establish history; unmaterialized empty TUIs may be refused. The 26 regression tests include unsupported API cases, not proof of general first-input support.
