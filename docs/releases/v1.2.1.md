## Patch scope

- #319: discover native Claude registrations in known same-user Orca profiles on macOS when no explicit `CLAUDE_CONFIG_DIR` or `ANTHROPIC_CONFIG_DIR` selects a root. Explicit scope and precedence remain unchanged. Bounded metadata discovery preserves healthy rows on partial failure but refuses all target selection when inventory is incomplete or live records conflict. Selected record/profile and inbox evidence is retained and rechecked; ordinary socket aliases remain supported, while their existing optional-generation limitation remains. Discovery does not read credentials or transcripts, connect to an inbox, or prove receipt. Automatic Orca profile inventory is not new Windows/Linux support.
- #320: read bounded leading skill metadata independently of total document size. The 16 KiB header budget includes delimiters and line endings, with at most one extra byte of lookahead. Only the complete UTF-8 header is decoded; unreadable, unterminated, over-budget or invalid-UTF-8 headers remain unknown. Existing constrained field extraction is not a general YAML validator; legacy accepted forms remain accepted. Existing field, manager and symlink behavior is preserved; nonregular input yields unknown metadata, and an invalid numeric field does not erase a separately valid field. No YAML or skill instructions are executed.
