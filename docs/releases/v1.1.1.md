# v1.1.1 maintenance release

## Scope

Prepared on 2026-10-12 against 1.1.0. This patch maintains documentation and development-only tests; runtime behavior is unchanged. Verify [GitHub publication](https://github.com/abruption/session-peer/releases/tag/v1.1.1) and [PyPI files](https://pypi.org/pypi/session-peer/1.1.1/json) independently. Preparation alone does not establish publication or deployment.

## Changes

- #297: update the development-only SSH fixture dependency to Paramiko 5.0.0 and its pin test. Runtime SSH still uses system OpenSSH; Paramiko is not a shipped runtime dependency.
- #281 / #299: align four-locale README, release runbook, documentation index and handoff guide with published 1.1.0 evidence; preserve historical release commands and add regressions for stale version statements.
- Prepare package and documentation version 1.1.1 without expanding experimental handoff support or changing the frozen contract.

## Validation and known limits

Require fresh exact-head CI, full local tests, standalone regeneration, isolated wheel/sdist installation, four-locale checks and current dependency audits before publication. GitHub immutable assets and required human PyPI environment review remain separate gates. No new live agent, SSH, Relay or fleet acceptance is established by these documentation/test changes.

#298 remains open: invalid Claude PID records can disrupt healthy discovery, and nondecimal Unicode session names can fail target resolution. This patch does not fix that runtime defect.

Experimental handoff retains the 1.1.0 scope: local POSIX Claude receipt ACKs, correlation-only Codex/SSH submission and unsupported observation/ACK routes described in the [handoff guide](../handoff-runtime.md). `posted`/`queued` is not consumption or ACK; unknown outcomes never authorize automatic resend. The historical RC4 ACK count remains 20/21 and #161 remains unresolved; historical evidence is not new 1.1.1 acceptance.

Package publication does not include operational deployment. Control/Relay deployment, installed fleet versions and hosted availability require separate verification. This patch does not establish remediation of every repository vulnerability.
