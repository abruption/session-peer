# v1.1.1维护发布

## 范围

于2026-10-12基于1.1.0准备。此补丁维护文档和开发用测试，不改变运行时行为。分别检查[GitHub发布](https://github.com/abruption/session-peer/releases/tag/v1.1.1)和[PyPI文件](https://pypi.org/pypi/session-peer/1.1.1/json)。仅完成准备不能证明已发布或部署。

## 变更

- #297：将开发用SSH测试依赖更新至Paramiko 5.0.0，并修改固定版本测试。运行时SSH仍使用系统OpenSSH；Paramiko不是发布包的运行时依赖。
- #281 / #299：让四种语言的README、发布流程、文档索引和handoff指南与已发布1.1.0的证据一致，保留历史发布命令，并增加防止过时版本描述的回归测试。
- 准备软件包及文档版本1.1.1，不扩展实验性handoff支持范围，也不改变冻结契约。

## 验证与已知限制

发布前要求重新执行准确最新提交的CI、全部本地测试、单文件重新生成、隔离wheel/sdist安装、四种语言检查和最新依赖审计。GitHub不可变资产和必需的人工PyPI环境审核仍是独立门禁。这些文档与测试变更不能证明完成了新的真实代理、SSH、Relay或设备验收。

#298仍未解决：无效Claude PID注册文件可能干扰正常会话发现，非十进制Unicode数字会话名称可能导致目标解析失败。此补丁不修复该运行时缺陷。

实验性handoff保留1.1.0范围：本地POSIX Claude接收ACK、仅支持关联的Codex/SSH提交，以及不支持的观察与ACK路径，详见[handoff指南](../handoff-runtime.md)。`posted`/`queued`不表示消费或ACK；不确定结果不允许自动重发。历史RC4 ACK计数仍为20/21，#161仍未解决；历史证据不是新的1.1.1验收证据。

软件包发布不包含生产环境部署。Control/Relay部署、设备安装版本及托管服务可用性需要单独验证。此补丁不表示仓库中的所有漏洞都已修复。
