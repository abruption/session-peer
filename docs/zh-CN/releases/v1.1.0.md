# v1.1.0 发布候选

## 状态与前提条件

这是2026-10-09准备的未发布候选，当前已公开稳定版仍为1.0.4。PR #261与功能PR #283–#290已通过正常保护流程合并。功能集成基准为 `3b328799b73b69e3640534ce229ec5ba565ca894`；此次准备仅增加版本与文档变更，并非发布。准备PR的准确提交须通过CI，创建版本前还须复核已批准的最终main。

## 计划变更

- #242 / #283：Bash/zsh和PowerShell 5.1的可选 `sp` shell别名通过正式的 `session-peer` 保留参数、标准输入和退出码。wheel/sdist包含手动启用文件；与现有别名、函数或可执行文件冲突时拒绝，包括PowerShell默认别名。不修改配置文件/PATH，不自动启用，不提供Python/TypeScript选择器。独立文件安装需要另行审查的文件。
- #268 / #284：继承的 `CODEX_SQLITE_HOME` 或已检查配置中的顶层 `sqlite_home` 会在发现、队列提交或wake之前触发安全拒绝。这是有界的存储布局保护，并非迁移数据库支持或对Codex所有有效配置的证明。
- #232 / #285：外部消息正文以引用形式呈现，来源与回复路径声明标记为未经验证。配对接收端的认证身份指设备密钥，不是人员或模型。正文分隔并非通用提示注入防御；额外文本计入容量限制，`chars` 表示处理后的完整文本。
- #180 / #286：可选Claude `targetGeneration` 发现与 `--target-generation` 固定原进程/端点，并在写入前复核已连接的对端。过期目标在执行前被拒绝。Codex、Antigravity和配对设备的代际保证仍不支持；writer重启不会将不支持状态提升为支持。
- #183 / #287：可选 `--ssh-identity` 报告连接主机密钥证据，`--require-ssh-host-key` 在认证或远程执行前固定实际连接的密钥。支持POSIX普通Ed25519/RSA/ECDSA密钥，不支持主机证书与安全密钥类型。主机密钥不代表代理身份、会话代际或ACK。
- #238 / #288：协作式wake深度/来源传递和有界的目标调用频率限制补充现有保护。环境变量被过滤或丢失后可能建立新来源，共享MCP启动环境不是每次调用的上下文。原生wake仍限于先前验证的Codex 0.154.0路径。
- #211 / #289：`session-peer setup` 提供本地/SSH/Relay只读检查与明确批准的操作。默认检查不创建密钥或数据库，安装管理器指导不会自动安装。不扩大现有策略，持久保存原注册请求，准备检查不发送消息。前台接收端设置不安装服务。
- #181 / #290：实验性可选handoff增加发送端持久提交约束、有时间与容量限制的标准输入/进程处理，以及仅用于收据的状态、等待、ACK操作。本地POSIX Claude支持已验证的原代际收据路径；本地Codex与单目标POSIX源码流式SSH仅支持关联标识提交，观察与ACK不支持。必需的delivered/acknowledged等待在不支持路径上于执行前拒绝。远程收据、Windows、配对handoff、多主机可选模式、不读取正文的Codex观察及完整恢复验收仍为独立条件。

## 兼容性与安全边界

核心需要Python 3.9以上，MCP需要3.10以上，Unix/WSL Relay需要3.11以上。关闭可选功能时，普通结果保留原生可选字段。`posted`、`queued`、`submitted` 不证明消费；未知结果不允许自动重发。实验性等待按目标默认30秒，使用整数1–60秒总预算与5秒清理预留。状态与收据操作不提交原生消息。收据权限证明持有令牌，而非模型身份；接收端原生历史可能保留委托权限。

分隔后的完整正文适用Codex/配对32 KiB、配对应用JSON 64 KiB（包含JSON转义）、worker 256 KiB和队列记录1 MiB限制。普通SSH保留90,000字符和命令131,071字节限制。完整有效的原生响应可在传输失败后保留；不完整或超过协议容量的输出仍属不确定。

随附技能仍为0.3.2，最低/完整运行时兼容性为0.9.1/1.0.1。独立技能PR #30尚未发布；新说明须先完成合并、发布与准确快照同步，不属于此候选。#180、#181和#268明确不支持的验收条件继续保留，此草案不关闭这些问题。

## 验证与发布条件

本地集成候选验证覆盖受控测试与隔离安装，不是新的实际代理/SSH/Relay验收。版本变更后必须重新验证准确集成main的CI、独立文件再生成、四语言文档检查、隔离wheel/sdist安装、手动启用文件检查及当前依赖审计。历史20/21 ACK证据与未关闭#161不变，不验证1.1.0。剩余平台与能力条件须保持明确。

软件包发布不包括生产部署。标签、不可变资源、GitHub/PyPI发布、人工PyPI环境审核、所有设备安装及Control/Relay部署是须按现有权限批准的独立步骤。本文档不证明已发布、服务已重启或新的可用性。
