# v1.2.0发布候选版本

## 范围

于2026-10-15基于已发布1.1.2准备。候选版本尚未发布，2026-10-18里程碑目标并非发布承诺。本准备分支仅修改版本和文档。以下提案必须先合并各自PR并通过集成检查，才能纳入发布。

于顺序集成期间的2026-10-16更新。最终main同步、最新提交审核和集成验证仍待完成；此处不宣称最终main SHA或发布完成。

#311的macOS发现策略仍仅检查元数据：独立list不执行Codex或查询版本，而是保守检查普通及强制偏好设置，因此也可能拒绝native加载器会忽略普通值的新环境。send/dry-run使用有界native版本证据，仅准确审核的0.162.1选择仅强制值检查；旧版、无法确认或未审核版本也检查普通值。物理child cwd和消费端路径别名检查只能减少已知配置歧义，不能消除启动存储或原子身份的不确定性。

原因不明的Relay exit139与单独的本地关闭诊断仍在#316监测。重跑成功不能证明原因、关联或已修复。不得绕过测试、审计或保护规则。

## 拟议变更

- PR #311：拒绝额外配置层中的已知Codex存储重定向，并在产生效果前检查queue执行计划。共享daemon路由仍由native选择；检查通过不等于实际存储身份认证。
- PR #310：保持Codex目标世代不支持状态，增加反例测试；writer锁、queue ID和turn ID均不能证明原始世代的原子一致性。
- PR #314：离线测试不安全/失效通道、保留期、明确已知恢复的隔离，以及collector重启后已提交ACK分类保持不变。不增加运行时支持。
- PR #305：保存macOS/Linux Antigravity 1.3.3注册后的有限验证。Antigravity仍为实验性功能，并非稳定支持。
- PR #313：保存2026-10-13 macOS启动和接收端bridge的历史证据，区分owner接收与调用方执行，并说明来源限制。
- PR #308：强化隔离Codex首次输入probe。无法确认服务器历史时安全拒绝，因此未持久化的空TUI可能被拒绝。26项回归测试包括不支持API的情况，并非一般首次输入支持的证据。

## 验证与剩余门禁

需要最新提交审核/CI、顺序集成、独立文件再生成、翻译哈希、完整平台测试、隔离wheel/sdist安装和最新依赖审计。单独分支通过不代表最终集成树已验证。所有合并后须通过准确main CI，审核7项不可变草稿资产和证明，并获得必需的人工pypi环境批准。准备不授权合并、创建标签/草稿、派发工作流、发布或部署。

发布准备PR必须在范围内全部6项PR合并后最后合并。更新准备PR以反映已合并main，并审核最终提交；历史批准不授权v1.2.0。准备分支CI和本地集成产物仅为演练证据，不是可发布的版本资产。受保护最终main的CI成功后，通过获批的准备工作流从该准确main提交重新构建并验证资产，发布前审核全部7项不可变资产及证明。发布时应核实实际发布证据，再更新四种语言README的稳定版/候选提示和发布说明，不得提前宣称已发布。

议题#180、#181、#268、#304、#306、#307仍保持开放。本候选不提供native Codex世代/ACK、完整存储验证、一般空TUI输入、Antigravity稳定支持及剩余native/平台验收。固定handoff契约和fixture不变；submitted/queued不等于消费或ACK，unknown永不授权自动重发。

插件和独立技能版本分别管理且不变。不宣称新增实际SSH、Relay、MCP、OAuth、设备群或native代理验收证据。历史RC4 ACK证据保持20/21；#161仍为根因未确认的监测项。软件包发布不包含生产部署；Control/Relay部署和已安装设备更新需另行批准与验证。
