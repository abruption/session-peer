# 공개 WSS 파일럿 — 2026-09-17

사용자 승인을 받은 임시 KR 파일럿으로, 완료 후 제거되었습니다. 이는 제한된 통합 확인이며 프로덕션 배포나 지속적인 운영 결과가 아닙니다.

## 경로 및 격리

Mac 클라이언트 → 공개 Cloudflare HTTPS/WSS → KR Caddy 정확한 테스트 호스트 이름 → 127.0.0.1:3769 블라인드 릴레이 → 인증된 수신자 → 기존 Antigravity 브리지.
애플리케이션 TLS 1.3 채널은 WebSocket 내부에서 기기 인증서를 고정합니다. 공용 TLS 종단점은 애플리케이션 일반 텍스트를 수신하지 않습니다. 네이티브 접근은 명시적으로 허용된 하나의 피어와 기존 `agy-kr` 세션 별칭으로 제한되었습니다.

테스트 전에 이전 SSH 포워딩 프로세스를 중지했습니다. 공용 목적지 라우팅은 Tailscale 인터페이스가 아닌 en1 / 로컬 인터넷 게이트웨이를 사용했습니다. SSH는 관리 및 읽기 전용 트랜스크립트 관찰용으로 별도로 사용되었습니다. 이는 VPN이 비활성화된 휴대전화 테스트나 순수 TCP NAT 통과를 입증하는 것은 아닙니다.

릴레이는 DynamicUser, ProtectHome, ProtectSystem=strict, NoNewPrivileges, 256 MiB 메모리, 50% CPU, 64개 작업, 10개 연결 애플리케이션 제한 및 30분 런타임 상한으로 실행되었습니다. Caddy 변경 전에 독립적인 30분 systemd 정리 타이머가 설정되었습니다. DNS나 방화벽 변경은 이루어지지 않았습니다.

## 관찰 결과

- 공개 미인증 입장: HTTP 401.
- 인증된 페어링 `list`: 기존 Antigravity 세션 반환됨.
- 공개 전송 마커: `SP090_PUBLIC_e037d3d2d993`.
- 요청 ID: `e037d3d2-d993-4fae-8c03-dbc66619967c`.
- 네이티브 결과: 제출됨, `consumptionConfirmed=false`.
- 독립적으로 관찰된 MODEL 트랜스크립트: `ACK_SP090_PUBLIC_e037d3d2d993`.
- 동일한 요청 ID/본문 반복: `duplicate=true` 및 동일한 네이티브 요청 ID를 가진 지속 영수증. 두 번째 네이티브 제출은 요청되지 않았습니다.

독립적으로 관찰된 이 ACK는 이 특정 메시지에 대한 근거를 강화합니다. 이것이 일반적인 전송 계약을 전달 확인으로 변경하거나 비정상 종료 시 정확히 한 번 전달을 입증하지는 않습니다.

## 정리

다른 구성을 보존하면서 정확한 임시 Caddy 블록을 제거했습니다. 검증/다시 로드가 성공했습니다. Caddy SHA256이 테스트 전 값인 `60ae35627b82d65724ceac89421e1f92ba475b675fd146b4036129f352197ebb`로 복원되었습니다. 공개 테스트 호스트 이름은 원래의 HTTP 301 응답을 반환했습니다. 릴레이 서비스가 중지되었고 루프백 포트 3769가 닫혔습니다. 정리 타이머는 성공적인 롤백 후에만 해제되었습니다. 임시 수신자와 네이티브 브리지가 중지되었으며, 사용자의 Antigravity TUI는 계속 실행 상태를 유지했습니다. 테스트 자격 증명과 임시 서비스 설치는 이후 제거되었습니다.
