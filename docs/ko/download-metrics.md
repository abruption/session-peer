# 다운로드 지표

README의 PyPI 월간 다운로드 배지는 [Pepy](https://pepy.tech/pepy-api)에서 직접 제공됩니다. 배지를 클릭하면 [session-peer 통계](https://pepy.tech/projects/session-peer)가 열립니다. 공개 월간 배지는 달력 기준의 월이나 실시간 카운터가 아닌 최근 30일을 집계합니다. Pepy의 API 문서에 따르면 공개 배지 엔드포인트는 API 키가 필요 없고, 속도 제한이 없으며, 12시간 동안 캐시됩니다. GitHub 이미지 캐싱으로 인해 가시적인 업데이트가 추가로 지연될 수 있습니다. 배지는 여전히 외부 의존성입니다.

월간: `https://api.pepy.tech/badge/session-peer/month`.
주간: `https://api.pepy.tech/badge/session-peer/week` (최근 7일).

## 해석

- 이는 Pepy의 집계치입니다. 공개 배지 문서는 PyPI Stats와 동일한 미러/CI 필터링을 보장하지 않습니다. 두 제공업체를 혼동하거나 CI 트래픽이 제외되었다고 주장하지 마십시오. 다운로드 측정 제한 사항에 대해서는 [PyPA 가이드](https://packaging.python.org/en/latest/guides/analyzing-pypi-package-downloads/)를 참조하십시오.
- 이러한 집계치는 레거시 `cc-peer`, GitHub 클론, 원시 스크립트 설치 또는 모든 패키지 소스가 아닌 `session-peer` PyPI 패키지만을 대상으로 합니다.
- 배지를 사용할 수 없거나, 속도 제한이 걸렸거나, 알 수 없는 상태라고 해서 다운로드 수가 0인 것은 아닙니다. 맥락을 확인하려면 소스 링크를 따르십시오. README는 하드코딩된 수치로 대체하지 않습니다.

배지는 기존 README 배지와 마찬가지로 원격 이미지입니다. CLI 텔레메트리나 저장소 소유의 수집기, 데이터베이스 또는 예약된 워크플로를 도입하지 않습니다. 버전은 변경되지 않으며, 문서 업데이트는 릴리스를 필요로 하지 않습니다.

## 별도의 랜딩 페이지 구현

온톨로지 세션이 랜딩 페이지를 소유합니다. 소스 및 제공업체 오류 상태를 명확히 유지하면서, 별도로 레이블이 지정된 최근 7일 및 최근 30일 PyPI 지표에 동일한 Pepy 공개 주간 및 월간 배지를 사용하십시오. 이를 통해 JSON API 키나 별도의 수집기를 피할 수 있습니다. 공개 코드에 Pepy JSON API 키를 노출하지 마십시오. JSON API 접근에는 공개 배지와 다른 인증, 요금제 및 속도 제한 조건이 있습니다. 기존 사이트 분석은 그대로 유지되며, 이번 작업으로 CLI 또는 방문자 이벤트 텔레메트리가 추가되지 않습니다.

## 제공업체 변경 검증 (2026-09-18)

원래 Shields.io 배지는 PyPI Stats를 사용했습니다. 직접 PyPI Stats에 요청 시 HTTP429가 반환되었고 원래 배지에는 이전에 업스트림 속도 제한 오류가 표시되었습니다. 추가적인 이미지 캐시 매개변수가 업스트림 의존성을 제거하지는 못합니다. curl을 사용했을 때 두 Pepy 공개 엔드포인트 모두 HTTP200과 session-peer에 대한 SVG 숫자 배지(관찰 시점에 반올림된 레이블 월간 `2k` 및 주간 `1k`)를 반환했습니다. 이렇게 반올림된 관찰치는 README에 하드코딩되지 않으며 정확한 정수 수치나 장기적인 서비스 가용성을 보장하지 않습니다. 초기 Python urllib 요청은 403을 반환했으므로 curl 결과를 모든 클라이언트로 일반화해서는 안 됩니다. 브라우저 및 GitHub 이미지 프록시 접근성은 별도의 확인 대상으로 남아 있습니다.

## GitHub 후속 조치

[GitHub 릴리스 API](https://docs.github.com/en/rest/releases/releases)는 업로드된 릴리스 에셋에 대한 누적 `download_count`를 노출합니다. 주간/월간 수치를 확인하려면 날짜가 기록된 스냅샷과 안정적인 에셋 ID별 차이값이 필요합니다. 기준선 누락, 제거되거나 교체된 에셋, 카운터 감소에는 명시적인 알 수 없음 또는 연속성 상태가 필요합니다. 하나의 누적 측정값에서 과거 기간을 복구할 수는 없습니다. GitHub 에셋 다운로드는 PyPI와 별도로 유지하고 클론이나 원시 독립형 설치 프로그램 트래픽으로 라벨을 지정하지 마십시오. 이번 첫 번째 README 변경에는 스냅샷 자동화가 구현되지 않았습니다.
