# session-peer 0.7.0

이번 릴리스에서는 읽기 전용 진단 및 안전하고 구조화된 회신 라우팅이 추가되었으며, 로컬 및 원격 워크플로 전반에서 JSON 응답과 업데이트 알림이 일관되게 적용되었습니다.

## 변경 사항

- 로컬 및 SSH를 통해 `session-peer doctor`를 추가합니다. 인박스에 연결하거나 큐를 작성하지 않고도 누락되거나 잘못된 홈, 사용할 수 없는 Claude 인박스, 누락된 Codex 실행 파일, 권한 실패, 지원되지 않는 Codex 상태 스키마 및 알 수 없는 검사 결과를 구분합니다.
- 옵트인 `doctor --check-return-route`를 추가합니다. 대상은 비밀번호 프롬프트, 호스트 키 등록 및 키 업데이트가 비활성화된 고정된 비대화형 `ssh ... true` 경로를 출발지로 되돌아가며 테스트합니다. 순방향 SSH 성공이 역방향 접근의 증거로 취급되지 않습니다.
- 로컬 또는 SSH 트랜스포트를 통한 Claude 및 Codex용 버전 관리형 `session-peer://v1/reply` 주소를 추가합니다. 파서는 모든 필드의 유효성을 검사하고 충돌하는 CLI 라우팅 및 안전하지 않은 입력을 거부하며 주소를 셸 구문으로 평가하지 않습니다. 현재 머신의 동일 사용자 주소는 로컬 전달로 정규화됩니다.
- 호환성을 위해 기존의 사람이 읽을 수 있는 `Reply:` 명령어를 유지합니다. 이제 전송 JSON은 공지된 `replyRoute` 및 구조화된 주소 `addressResolution`을 노출합니다.
- `schemaVersion`, `ok`, `host` 및 `command`를 사용하여 모든 JSON 결과를 스키마 버전 1로 표준화합니다. 로컬 또는 단일 호스트 명령어는 하나의 객체를 반환하며, 반복된 `--host`는 호스트별 독립적인 성공 또는 실패가 포함된 순서화된 배열을 반환합니다.
- 비공개 24시간 업데이트 캐시와 비차단 백그라운드 새로고침을 추가합니다. 새로운 GitHub 릴리스 레코드를 통해 호출 클라이언트가 뒤처져 있음이 확인되면 JSON에 `clientUpdate`가 추가되고 사용자 출력에 일치하는 업그레이드 명령어가 인쇄됩니다. 오프라인, 만료, 최신 및 옵트아웃 상태는 요청된 명령어를 지연시키거나 변경하지 않습니다.

## 회신 관찰에 대한 결정

이번 릴리스에는 일반적인 `--wait`가 없습니다. Claude의 지원되는 유휴 알림은 다른 로컬 Claude 세션을 관찰하는 메인 Claude 대화로 제한되는 반면, Codex 큐 제출에는 이에 상응하는 에이전트 간 확인 관찰자가 없습니다. 트랜스크립트 폴링은 다른 요청, 오래된 출력 또는 에코를 회신과 혼동할 수 있습니다. 따라서 `doctor`는 회신 관찰을 지원되지 않음(unsupported)으로 보고합니다. 완료 워크플로에는 상관관계 토큰을 포함하고 구조화된 Reply-To 주소로 명시적 메시지를 요청해야 합니다.

## 호환성 및 제한 사항

- 공통 엔벨로프는 문서화된 JSON 계약 변경 사항입니다. 소비자는 모든 결과에서 `ok`를 확인하고 대상 수에 따라 객체 또는 배열을 처리해야 합니다.
- 감지 가능한 발신자 및 반환 경로가 있는 메시지는 기존 `Reply:` 명령어 외에도 `Reply-To:` URI를 얻습니다. `--no-reply-to`는 둘 다 억제합니다.
- Doctor 확인은 증거일 뿐 전달이 아닙니다. Claude 인박스 존재 여부는 실제 전송 전까지 파일 시스템 수준에서만 확인되며, Codex가 큐에 추가되었다고 해서 소비되었거나 확인되었음을 의미하지는 않습니다.
- 역방향 경로 테스트는 절대 자동으로 수행되지 않습니다. 키를 추가하거나, 다른 계정으로 재시도하거나, 호스트 키 정책을 완화하거나, SSH 구성을 변경하지 않습니다.
- Codex 홈 검색은 선택된/기본 홈, 구성된 홈 및 지원되는 Orca 계정 홈으로 제한됩니다. 임의의 루트를 스캔하지 않습니다.

## 업그레이드

설치를 관리하는 패키지 관리자를 사용하세요:

```bash
pipx upgrade session-peer
uv tool upgrade session-peer
python -m pip install --upgrade session-peer
```

독립형 설치는 `session-peer update`를 실행할 수 있습니다. 번들된 Claude 스킬도 새로고침해야 하는 경우 v0.7.0 체크아웃에서 `install.sh`를 다시 실행하세요.

## 검증

- 명시적 `tests/` 검색과 기본 unittest 검색 모두에서 240개의 단위 및 통합 테스트를 통과했습니다.
- CI는 Ubuntu 및 macOS(Python 3.9/3.13), Windows(Python 3.13), 패키지 빌드 및 격리된 설치, 독립형 설치 스모크 테스트, shellcheck 및 시크릿 스캐닝을 다룹니다.
- Wheel 및 sdist 내용을 검사하고 독립적으로 설치했습니다. CLI, 모듈 및 패키지 메타데이터는 v0.7.0을 보고하며 어떤 아티팩트도 동결된 레거시 `cc_peer.py`를 포함하지 않습니다.
- 실제 SSH doctor 실행을 통해 Claude 인박스와 제한된 기본/Orca Codex 홈을 찾았습니다. 옵트인 역방향 프로브는 성공적인 순방향 연결과 무관하게 인증 실패를 보고했습니다. 릴리스 준비 과정에서 실제 Claude 또는 Codex 메시지를 제출하지 않았습니다.
