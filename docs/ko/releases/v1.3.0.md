# v1.3.0 릴리스 준비

## 소스와 공개 상태

공개된 1.2.1을 기준으로 2026-10-23에 준비했습니다. 이 문서는 릴리스 범위와 검증 조건을 기록하며 패키지 공개를 알리는 문서가 아닙니다. 공개 기록은 [GitHub Releases](https://github.com/abruption/session-peer/releases)와 [PyPI](https://pypi.org/project/session-peer/)에서 확인하십시오.

통합 소스 기준은 버전 준비 커밋 이전의 `a0e7af032fd372334782cc3ac3d97b21c71dd797`입니다. 기능 PR 6개는 #329, #330, #331, #332, #325, #328 순서로 병합했습니다. 이 기준의 [통합 CI](https://github.com/abruption/session-peer/actions/runs/39905198747)와 [CodeQL](https://github.com/abruption/session-peer/actions/runs/39905198891)은 통과했지만 최종 릴리스 커밋의 검증을 대신하지는 않습니다.

## 포함된 변경

- #323 / #325: `send --dry-run --explain`, `doctor --explain`, `handoff status --explain`의 텍스트 설명을 추가했습니다. 지원되는 페어링 대상의 준비 상태를 포함하여 기존 결과와 기록된 근거를 설명하며, 권한을 부여하거나 소비를 증명하지 않습니다. 구형 수신자의 추가 정보는 확인 불가로 남을 수 있습니다. 저장된 수신 확인 근거와 새 관측은 구분합니다.
- #324 / #328: Mac/Linux의 local/SSH Claude Code·Codex를 위한 선택적 경로 프리셋과 별도 수신자 주소록을 추가했습니다. 실제 주소록 전송에는 현재 `--address-revision`과 정확한 `--confirm-target`이 필요하며 선택 대상과 writer를 다시 검사합니다. revision은 사람의 신원을 인증하거나 native 세대·저장소의 원자적 일치를 증명하지 않습니다. Windows·페어링 기기·Antigravity 주소록 작업은 지원하지 않습니다.
- #296 / #329: 기존 intent를 관찰하는 유한 시간 POSIX `handoff watch`를 추가했습니다. 제출·재전송·collector·새 수신 확인 권한을 만들지 않습니다. 실험적 handoff의 범위와 기존 미지원 채널은 유지합니다.
- #312 / #330: 명시적으로 신뢰한 SSH 설정을 지원합니다. 신뢰한 설정은 로컬 SSH 명령을 실행할 수 있으므로 운영자가 신뢰 여부를 판단해야 하며 sandbox가 아닙니다. 기존 대상 검사와 불확실한 결과 처리는 유지합니다.
- #212 / #331: 숨김 터미널 입력과 별도 지문 확인을 사용하는 만료·일회용 페어링 링크와 안내형 설정을 추가했습니다. 양쪽은 지원되는 페어링 프로토콜과 기존 Unix Relay 요건을 충족해야 합니다. 페어링은 대상 정책이나 native 승인을 대신하지 않으며, 대기 중인 제안 취소는 완료된 페어링을 폐기하지 않습니다.
- #294 / #332: Mac/Linux에서 특정 버전의 자동 런타임 알림을 로컬로 숨기고 명시적으로 해제할 수 있습니다. 관리 작업은 오프라인이며 명시적 업데이트 확인과 스킬 알림의 기존 동작은 유지합니다.

정확한 조합·플랫폼 제한·오류 동작은 [CLI 안내](../cli-reference.md), [handoff 안내](../handoff-runtime.md), [페어링 기기 안내](../paired-devices.md)를 참고하십시오. 통합 변경에는 회귀 테스트 안정화와 만료된 Relay room의 사용 가능 여부 검사 수정도 포함됩니다. 재실행 통과만으로 이전의 별도 실패 원인이 밝혀지는 것은 아닙니다.

## 호환성과 남은 작업

핵심 런타임은 Python 3.9+를 유지합니다. 선택적 MCP는 Python 3.10+, Unix/WSL Relay receiver는 Python 3.11+가 필요합니다. 핵심 local/SSH 사용에 외부 Python 의존성을 추가하지 않습니다. 일반 제출 결과는 소비·수신 ACK·작업 완료와 구분합니다. 불확실한 결과는 자동 재전송을 허용하지 않습니다.

호환 스킬 사본은 companion 0.3.3이며 최소 런타임 0.9.1, 전체 안내 범위 기준 1.0.1을 유지합니다. companion의 1.3 안내는 별도로 검토하는 문서 변경입니다. 이 런타임의 공개가 해당 스킬의 설치나 공개를 뜻하지 않습니다. 플러그인과 TypeScript 버전도 독립적입니다.

Side Session·steering 연구(#245/#247, Draft #246/#248)는 Long-term에 배정했으며 릴리스 기능이 아닙니다. 남은 native 세대·handoff·저장소·시작 시점 수락 조건(#180/#181/#268/#304/#306/#307)은 이 릴리스로 완료되지 않습니다. 일반 Codex ACK·첫 입력 전 전달·Antigravity 정식 지원을 새로 주장하지 않습니다.

## 릴리스 검증

준비 PR의 최신 리뷰·CI와 이후 보호된 main의 정확한 커밋에서 CI·의존성 감사를 통과해야 합니다. 생성된 독립 실행 파일의 일치, 4개 언어 문서, 패키지 내용과 신규 설치를 확인합니다. 로컬 통합·빌드 결과는 사전 검증 자료이며 공개 산출물이나 새로운 실제 에이전트·플랫폼 수락 검증이 아닙니다.

승인된 태그와 초안을 준비한 뒤 preparation workflow와 attach-draft 작업의 성공을 기다립니다. 공개 전에 불변 산출물 7개, `SHA256SUMS`, `release-provenance.json`, 인증된 attestation을 정확한 태그·커밋과 대조합니다. 사람이 수행하는 필수 PyPI 환경 승인은 유지합니다. 공개 증거는 별도로 기록하고, 고정된 이 문서를 수정하려고 불변 산출물을 교체하지 않습니다.

패키지 공개는 Control/Relay 서비스 배포나 설치된 기기의 업데이트를 포함하지 않습니다. 운영 적용과 실제 수락 검증은 별개입니다.
