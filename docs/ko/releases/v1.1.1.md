# v1.1.1 유지보수 릴리스

## 범위

1.1.0을 기준으로 2026-10-12에 준비했습니다. 이번 패치는 문서와 개발용 테스트를 유지보수하며 런타임 동작은 바꾸지 않습니다. [GitHub 공개](https://github.com/abruption/session-peer/releases/tag/v1.1.1)와 [PyPI 파일](https://pypi.org/pypi/session-peer/1.1.1/json)은 각각 확인하십시오. 준비만으로 공개나 배포가 확인되는 것은 아닙니다.

## 변경 사항

- #297: 개발용 SSH 테스트 의존성을 Paramiko 5.0.0으로 갱신하고 고정 버전 테스트를 수정합니다. 런타임 SSH는 계속 시스템 OpenSSH를 사용하며 Paramiko는 배포 런타임 의존성이 아닙니다.
- #281 / #299: 네 언어 README, 릴리스 절차, 문서 목차와 handoff 안내를 공개된 1.1.0 증거에 맞추고 과거 릴리스 명령을 보존하며 오래된 버전 표기의 회귀 테스트를 추가합니다.
- 실험적 handoff 지원 범위와 동결 계약을 바꾸지 않고 패키지·문서 버전 1.1.1을 준비합니다.

## 검증과 알려진 한계

공개 전 정확한 최신 커밋의 CI, 전체 로컬 테스트, 독립 실행 파일 재생성, 격리된 wheel/sdist 설치, 네 언어 검사와 최신 의존성 감사를 요구합니다. GitHub 불변 자산과 필수 사람 PyPI 환경 검토는 별도 조건입니다. 문서·테스트 변경만으로 새로운 실제 에이전트, SSH, Relay 또는 장비 검증이 성립하지 않습니다.

#298은 열려 있습니다. 잘못된 Claude PID 등록 파일은 정상 세션 탐색을 방해할 수 있으며 십진수가 아닌 Unicode 숫자 세션 이름은 대상 선택에 실패할 수 있습니다. 이번 패치는 이 런타임 결함을 수정하지 않습니다.

실험적 handoff는 1.1.0 범위를 유지합니다. 로컬 POSIX Claude의 수신 ACK, 상관 관계만 지원하는 Codex/SSH 제출과 미지원 관찰·ACK 경로는 [handoff 안내](../handoff-runtime.md)에 설명되어 있습니다. `posted`/`queued`는 소비나 ACK가 아니며 불확실한 결과는 자동 재전송을 허용하지 않습니다. 과거 RC4 ACK 집계는 20/21이고 #161은 미해결입니다. 과거 증거는 새로운 1.1.1 수락 증거가 아닙니다.

패키지 공개에는 운영 배포가 포함되지 않습니다. Control/Relay 배포, 장비 설치 버전과 호스팅 가용성은 별도로 확인해야 합니다. 이번 패치는 저장소의 모든 취약점이 해결되었음을 뜻하지 않습니다.
