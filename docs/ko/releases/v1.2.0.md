# v1.2.0 릴리스 후보

## 범위

공개 버전 1.1.2를 기준으로 2026-10-15에 준비했습니다. 후보는 미공개이며 2026-10-18 마일스톤 목표는 공개 약속이 아닙니다. 이 준비 브랜치는 버전·문서만 바꿉니다. 다음 제안 변경은 별도 PR 병합과 통합 검사 성공 후에만 릴리스에 포함됩니다.

## 제안 변경

- PR #311: 추가 설정 계층의 알려진 Codex 저장소 재지정을 거부하고 효과 전에 queue 실행 계획을 검사합니다. 공유 daemon 경로는 native에 맡기며 검사 통과가 유효 저장소 증명은 아닙니다.
- PR #310: Codex 대상 세대 미지원 동작을 유지하고 반례 테스트를 추가합니다. writer 잠금, queue ID와 turn ID는 원래 세대의 원자적 일치를 증명하지 않습니다.
- PR #314: 안전하지 않거나 오래된 채널, 보존 기간, 복원 사실이 확인된 이력의 명시적 격리와 collector 재시작 시 커밋된 ACK 분류 보존을 오프라인으로 검사합니다. 새 런타임 지원은 추가하지 않습니다.
- PR #305: macOS/Linux Antigravity 1.3.3 등록 후의 제한된 검증을 기록합니다. Antigravity는 정식 지원이 아닌 실험적 기능으로 유지합니다.
- PR #313: 2026-10-13 macOS 시작·수신측 bridge의 과거 증거를 기록하고 owner 수신과 호출자측 실행, 출처 한계를 구분합니다.
- PR #308: 격리된 Codex 첫 입력 probe를 강화합니다. 서버 이력을 확인하지 못하면 안전하게 거부하므로 저장되지 않은 빈 TUI는 거부될 수 있습니다. 회귀 테스트 26개에는 미지원 API 사례가 포함되며 일반적인 첫 입력 지원 증거가 아닙니다.

## 검증과 남은 조건

최신 커밋 검토·CI, 순차 통합, 독립 실행 파일 재생성, 번역 해시, 전체 플랫폼 테스트, 격리된 wheel/sdist 설치와 최신 의존성 감사가 필요합니다. 개별 브랜치 성공은 최종 통합본의 증거가 아닙니다. 모든 병합 후 정확한 main CI 성공, 불변 초안 자산 7개·증명 검토와 필수 사람 pypi 환경 승인을 요구합니다. 준비는 병합, 태그·초안 생성, 워크플로 실행 요청, 공개나 운영 배포 승인이 아닙니다.

릴리스 준비 PR은 범위 내 PR 6개를 모두 병합한 뒤 마지막으로 병합합니다. 병합된 main을 반영한 최종 준비 커밋을 갱신·검토하며 과거 승인은 v1.2.0 승인이 아닙니다. 준비 브랜치 CI와 로컬 통합 산출물은 예행 검증 자료이며 게시할 릴리스 자산이 아닙니다. 보호된 최종 main의 CI 성공 후 승인된 준비 워크플로로 정확한 main 커밋에서 자산을 다시 빌드·검증하고, 공개 전에 불변 자산 7개와 증명을 모두 검토합니다. 공개 시 실제 공개 증거를 확인한 뒤 README 4개 언어의 안정판·후보 안내와 릴리스 노트를 갱신하며 미리 공개 완료를 선언하지 않습니다.

이슈 #180, #181, #268, #304, #306, #307은 열린 상태입니다. native Codex 세대·ACK, 완전한 저장소 검증, 일반 빈 TUI 입력, Antigravity 정식 지원과 남은 native·플랫폼 수락 조건은 이 후보가 제공하지 않습니다. 고정된 handoff 계약과 fixture는 변하지 않습니다. submitted/queued는 소비·ACK가 아니며 unknown은 자동 재전송을 허용하지 않습니다.

플러그인·별도 스킬 버전은 독립적이며 바꾸지 않습니다. 새로운 실제 SSH, Relay, MCP, OAuth, 장비 전체 또는 native 에이전트 수락 증거를 주장하지 않습니다. 과거 RC4 ACK 증거는 20/21로 유지하고 #161은 원인 미확정 모니터링으로 남깁니다. 패키지 공개에는 운영 배포가 포함되지 않으며 Control/Relay 배포와 설치 장비 갱신에는 별도 승인·검증이 필요합니다.
