# v1.6.1 릴리스 준비

공개된 v1.6.0([GitHub](https://github.com/abruption/session-peer/releases/tag/v1.6.0), [PyPI](https://pypi.org/project/session-peer/1.6.0/))을 기준으로 2026-11-17에 준비했습니다. 이 날짜의 점검에서 v1.6.1은 미공개 소스 후보입니다. 통합 기준은 `0154c33f14dc5b9a64c4a3937c2eb50901ed28a4`이며 버전 준비 전 소스로, 최종 릴리스 커밋이 아닙니다. 소유자는 아래의 정확한 현재 head 검사와 공개 관문을 조건으로 릴리스 준비, 정상 검토·병합, 태그 생성과 발행을 승인했습니다. 이 기록은 그 단계들이 완료됐다는 뜻이 아닙니다.

## 후보 범위

- `f133153b32f68e39061d9c49d91e5042359e888f`로 병합된 [PR #401](https://github.com/abruption/session-peer/pull/401)은 릴리스 자산 인증 전에 실행되는 내장 `install.sh` 릴리스 검증기 호출을 `python3 -I -S -`로 바꿉니다. `-I`는 작업 디렉터리를 제외하고 `PYTHONPATH`를 무시하며, `-S`는 `sitecustomize`와 `usercustomize` 시작 훅을 포함한 자동 site 초기화를 막습니다. 대응하는 설치 프로그램 픽스처와 생성기 마커는 정본 검증기 계약 및 기존의 정상·거부 릴리스 동작을 보존합니다.
- [PR #403](https://github.com/abruption/session-peer/pull/403)은 핵심 Ubuntu/Python 3.9 CI 셀만 `ubuntu-latest`에서 `ubuntu-24.04`로 옮깁니다. Python 3.9와 핵심 셀 7개, 전체 CI 작업 49개를 유지합니다. 행렬 헬퍼는 제외 항목을 처리하고 정확한 셀을 검사합니다. 나머지 Linux latest, macOS, Windows, 패키지, MCP, Relay 범위는 그대로입니다. 앞선 설치 단계 실패는 제품 코드 회귀의 근거가 아닙니다.

## 보안과 호환성 경계

보안 변경은 자산 인증 전 내장 설치 검증기의 시작을 보호합니다. 모든 Python 실행을 격리하거나 기존 설치를 수리하거나 이미 공개된 불변 자산을 교체하지 않으며 배포된 설치의 실제 악용을 입증하지도 않습니다. 운영자가 선택한 인터프리터와 설치 프로그램에는 각각의 신뢰 요건이 남습니다. 공개된 v1.6.0 자산은 그대로이며 일반 공개 패키지 명령으로 이 미공개 후보가 제공되지는 않습니다.

핵심 Python 3.9, 선택 MCP Python 3.10, Relay Python 3.11 및 기존 SDK 제약은 그대로입니다. 의존성 업그레이드, 새 MCP 도구, 네이티브 에이전트·SSH·ACK 검증, 호출자 신원, 실효 저장소 증명이나 원자적 generation 보장을 추가하지 않습니다. #367과 별도 의존성·연구 작업은 계속 제외됩니다. 패키지 공개는 전역 설치, receiver·MCP 서버 재시작, Node Control 배포나 스킬 보급을 수행하지 않습니다.

## 검토와 검증 관문

통합 기준 `0154c33f14dc5b9a64c4a3937c2eb50901ed28a4`의 [main CI](https://github.com/abruption/session-peer/actions/runs/44003241812)는 성공했습니다. 이는 정확한 준비 head와 최종 보호 main 커밋의 독립 검토 및 검사를 대신하지 않습니다. 시작 훅·릴리스 검증기 픽스처는 통제된 시험이며 실제 악용이나 일반 네이티브 플랫폼 검증이 아닙니다. 승격 전에 재현 가능한 자산, 최신 의존성 감사와 별도의 새 환경 wheel/sdist 설치 검사를 요구합니다.

## 독립 스킬과 공개

예정된 `SKILL.md` 자산은 독립 공개 스킬 v0.5.1, 소스 `95cf5e1dd92654775b2f0ea86c1cb4b6107f49c3`, UTF-8 31688바이트, SHA-256 `922512869577cc3d8b9d305641479e2dd659f0e669298584ca06f1ca15de1d31`을 유지합니다. 최소 런타임 0.9.1, 문서화된 전체 흐름 범위 1.4.0과 receiver `codexBin` 하한 1.0.1도 그대로입니다. 자산은 wheel/sdist 밖에 있으며 스킬 버전·호환성 하한·소스 핀·설치된 스킬을 바꾸지 않습니다.

[v1.6.0 공개 기록](v1.6.0.md#v160-publication-record), 날짜가 있는 모든 준비 기록과 불변 태그·자산을 보존합니다. 승인된 공개에도 `SHA256SUMS`와 `release-provenance.json`을 포함한 고정 자산 7개, 정확한 소스·태그와 인증된 attestation, 최신 감사·설치 검사 및 PyPI 환경의 필수 검토자 승인이 필요합니다. 비공개 로그인·binding 재확인 생략은 이 승인을 면제하거나 보호 우회를 허용하지 않습니다. 실제 GitHub/PyPI 공개 근거는 별도로 추가하고, 미리 제공을 발표하거나 옛 자산을 교체하지 않습니다.
