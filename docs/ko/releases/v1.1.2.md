# v1.1.2 패치 후보

## 범위

공개된 1.1.1을 기준으로 2026-10-13에 준비했습니다. 이 후보는 미공개이며 #298만 수정합니다. 준비 작업은 병합·태그 생성·공개·운영 배포 승인이 아닙니다.

## 변경 사항

- 운영체제의 프로세스 검사 전에 Claude 등록 기록의 PID를 범위 내에서 해석하고, 잘못된 기록을 개별 처리하여 정상 세션 검색을 유지합니다.
- ²와 같은 비십진 유니코드 세션 이름은 정수 변환 대신 이름으로 선택합니다. 유효한 PID 지정과 중복 이름 거부는 유지합니다.
- 진단에도 같은 범위 제한 기록 처리를 적용하고 권한 진단을 유지하며 독립 실행 CLI를 재생성합니다.

## 검증과 알려진 한계

잘못된 파일 이름, 지나치게 큰 PID, 정상 세션 유지, 유니코드 이름 지정 및 메시지 제출 없이 발생하는 전달 전 실패에 대한 회귀 테스트가 필요합니다. 공개 전에 정확한 최신 커밋의 플랫폼 CI, 전체 로컬 테스트, 독립 실행 파일 재생성, 네 언어 검사, 격리된 wheel/sdist 설치와 최신 의존성 감사를 완료해야 합니다. 준비 노트는 이 조건을 통과했다는 증거가 아닙니다.

새로운 실제 Claude·Codex·Antigravity·SSH·Relay 또는 장비 검증 결과를 주장하지 않습니다. Windows PID 재사용, 프로세스 시작 시각과 소유자 검사는 계속 필요하며 새 전송 경로나 에이전트 지원은 추가하지 않습니다.

실험적 Handoff는 [Handoff 가이드](../handoff-runtime.md)에 설명된 1.1.0 범위를 유지합니다. 메시지 제출은 소비나 ACK가 아니며 결과가 불확실하면 자동 재전송을 허용하지 않습니다. 과거 RC4 ACK 수는 20/21로 유지하며 #161은 원인 미확정 상태로 관찰을 계속합니다.

패키지 공개에는 운영 배포가 포함되지 않습니다. Control/Relay 서비스와 설치된 장비는 별도 승인과 검증이 필요합니다. GitHub 불변 자산과 필수 사람 PyPI 환경 검토는 별도의 조건입니다.
