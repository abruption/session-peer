# v1.4.1 유지보수 릴리스 준비

공개된 v1.4.0을 기준으로 2026-11-03에 준비했습니다. 이 날짜의 확인 시점에서 v1.4.1은 미공개 후보입니다. 통합 유지보수 기준은 버전 준비 이전의 `192b77ec4a168859c26fe886ff42901f24060608`이며, 최종 릴리스 커밋이 아닙니다. 소유자가 릴리스를 승인했어도 정상 저장소 보호 절차, 현재 HEAD 검토와 최종 보호된 main CI를 거쳐야 합니다.

## 범위

- PR #366은 별도로 공개된 스킬 v0.5.0을 반영했고, PR #369는 호환 사본을 v0.5.1로 동기화하며 네 언어의 v1.4.0 공개 기록과 현재 상태 안내를 추가했습니다. 이번 패치는 이 문서·호환 사본 유지보수를 배포물에 반영합니다. 버전 값 외의 런타임 동작은 바뀌지 않으며, 런타임 결함을 수정했다고 주장하지 않습니다.
- 예정된 `SKILL.md` 지원 자산은 공개된 [스킬 v0.5.1](https://github.com/abruption/session-peer-skill/releases/tag/v0.5.1), 소스 `95cf5e1dd92654775b2f0ea86c1cb4b6107f49c3`, UTF-8 31688바이트, SHA-256 `922512869577cc3d8b9d305641479e2dd659f0e669298584ca06f1ca15de1d31`입니다. 메타데이터는 스킬 0.5.1 / 최소 런타임 0.9.1 / 문서 전체 기준 1.4.0을 유지하며, 수신측 `codexBin` 하한도 1.0.1입니다. 이번 런타임 패치에 사본이 포함된다는 이유로 문서 기준을 1.4.1로 올리지 않습니다. 스킬 릴리스 API는 `immutable=false`를 반환하며, 정확한 소스·해시 고정이 GitHub의 불변성 보장을 뜻하지는 않습니다.
- 불변 런타임 v1.4.0의 `SKILL.md` 자산은 스킬 v0.4.1로 유지됩니다. 기존 태그·자산과 과거 준비·공개 기록을 보존합니다. 런타임 패키지 갱신은 별도로 관리되는 스킬이나 다른 전역 MCP 환경을 갱신하지 않으며, 수신기를 재시작하거나 Node Control 서비스를 배포하지도 않습니다.
- [#370](https://github.com/abruption/session-peer/issues/370)은 출력 실패를 주입했을 때 테스트 코드의 읽기가 무기한 대기할 수 있음을 기록하며, 원래 CI 정지 원인은 아직 확인되지 않았습니다. 이번 패치는 #370을 수정하지 않습니다. [#367](https://github.com/abruption/session-peer/issues/367)의 페어링 기기 전체 조회와 Long-term 연구는 별도입니다. 새 기능, 새로운 실제 Native/SSH, Windows 3.14·free-threaded Python, 소비·ACK 또는 플랫폼 지원 검증을 주장하지 않습니다.

기본 Python 3.9, MCP Python 3.10+ 및 SDK 요구사항 `mcp>=1.30,<2`는 그대로입니다. 지원 스킬은 wheel/sdist에 포함되지 않습니다.

## 발행 조건

정확한 준비 HEAD와 최종 보호된 main 소스의 검사·리뷰 통과가 필요합니다. 고정 자산 7개, `SHA256SUMS`, `release-provenance.json`과 인증된 증명을 정확한 태그·소스에 맞춰 빌드·검증하고, 의존성 감사와 새 환경의 wheel/sdist 설치 검사를 수행해야 합니다. 이는 남은 릴리스 조건이며 이번 준비에서 완료를 주장하는 결과가 아닙니다. 비공개 로그인·연결 재확인을 생략해도 PyPI 환경의 필수 사람 승인은 유지합니다. 보호 절차를 우회하거나 공개된 태그를 옮기지 않습니다.

날짜가 명시된 이 노트를 고정하고 실제 GitHub/PyPI 공개 근거는 별도로 추가합니다. 이전 릴리스는 [v1.4.0 공개 기록](v1.4.0.md#v140-publication-record)을 참고하세요. 발행과 운영 배포는 별개입니다.
