## 패치 범위

- #319: 명시적 `CLAUDE_CONFIG_DIR` 또는 `ANTHROPIC_CONFIG_DIR`이 없을 때 macOS의 알려진 같은 사용자 소유 Orca 프로필에서 native Claude 등록을 검색합니다. 명시적 범위와 우선순위는 유지합니다. 제한된 메타데이터 검색은 일부 실패 시 정상 행을 보존하지만 검색이 불완전하거나 살아 있는 기록이 충돌하면 모든 대상 선택을 거부합니다. 선택한 기록·프로필·수신함 증거를 유지하고 다시 확인합니다. 일반 소켓 별칭은 유지하되 기존 선택적 세대 검사 제한도 유지합니다. 검색은 인증정보·대화 기록을 읽거나 수신함에 연결하지 않으며 수신을 증명하지도 않습니다. Orca 프로필 자동 검색은 새로운 Windows/Linux 지원이 아닙니다.
- #320: 문서 전체 크기와 별개로 제한된 앞부분의 스킬 메타데이터를 읽습니다. 16 KiB 헤더 한도에는 구분자와 줄 끝이 포함되며 추가 확인은 최대 1바이트입니다. 완결된 UTF-8 헤더만 해석하며 읽을 수 없거나 닫히지 않았거나 한도를 넘거나 UTF-8이 잘못된 헤더는 unknown으로 유지합니다. 기존의 제한된 필드 추출은 일반 YAML 검증기가 아니며 이전에 인식하던 형식은 계속 인식합니다. 기존 필드·관리 도구·심볼릭 링크 동작은 유지하며 일반 파일이 아닌 입력의 메타데이터는 unknown으로 처리합니다. 잘못된 숫자 필드가 별도로 유효한 필드를 지우지 않습니다. YAML이나 스킬 지침은 실행하지 않습니다.
- #303: companion v0.3.3의 소스 `eb239fb358336d85b49bab2c80e4ea39037d1374`, SHA-256 `15378c6d503a69d1d738ac4739182e23257aa6f2f7fd31ef3fd2fa60e692867f`에서 호환 스킬 사본을 갱신합니다. 스킬 메타데이터는 Python 1.2.1과 별개인 0.3.3 / 최소 0.9.1 / 전체 1.0.1입니다. 전역 스킬 설치나 다른 관리 도구로 설치한 사본의 갱신을 수행하는 변경은 아닙니다.

## 검증과 한계

최종 통합 소스, 생성된 독립 실행형 파일, 번역 해시, 패키지 내용과 설치된 CLI를 검토해야 합니다. 별도 브랜치의 검사 성공은 이번 준비의 증거를 대신하지 않습니다. 최종 커밋 CI·독립 검수·최신 의존성 감사가 남은 조건이며 별도 승인으로 준비 PR을 병합한 뒤에는 정확한 보호 main의 CI도 필요합니다. 로컬 빌드는 연습 검증의 증거이지 게시할 릴리스 자산이 아닙니다.

#319 최종 후보의 로컬 전체 실행은 1,294개 테스트 OK와 skip 19개로 끝났지만 asyncio AssertionError와 무시된 unclosed socket·transport ResourceWarning도 출력했습니다. 해당 소스 개정의 최초 로그를 보존했으며 진단을 숨기기 위해 재실행하지 않았습니다. #316은 열려 있고 테스트 성공이나 무관한 변경만으로 원인·수정을 입증하지 않습니다. #161과 #180/#181/#268/#304/#306/#307의 남은 수락 조건은 별도입니다. 과거 RC4 ACK 증거는 20/21로 유지합니다.

일반 Codex ACK·세대, 첫 입력 전 전달, Antigravity 정식 지원이나 완전한 native·플랫폼 수락을 추가하지 않습니다. 고정 handoff 계약·fixture는 불변이며 submitted/queued는 소비나 ACK가 아니고 unknown은 자동 재전송을 허용하지 않습니다. 플러그인 버전은 별개입니다. SSH·Relay·MCP를 통한 실제 에이전트 메시지·ACK 수락이나 OAuth·fleet·운영 수락은 주장하지 않습니다. 패키지 공개에는 운영 배포가 포함되지 않으며 Control/Relay와 설치된 기기의 갱신은 별도 승인·검증이 필요합니다.

2026-10-19에 소유한 MacBook에서 #319 소스 `ad4aa0e464fb142424f6fb6a30303bb88e47163e`를 소스 스트리밍 SSH로 실행해 메타데이터만 확인했습니다. 기본 검색, 선택적 `generationStatus=available` 메타데이터, 명시적으로 지정한 기본 경로 범위를 검증했습니다. 최종 #319 소스 `4cd202af4b6a2f0b5e7daa1e7f9d960eb7a67217`로 기본 검색을 다시 확인했을 때도 대상이 reachable로 나타났습니다. 두 검사 모두 런타임 설치나 native 수신함 입력은 수행하지 않았습니다. 이는 메타데이터 시점 관측이며 새로운 Python 1.2.1 실제 메시지·ACK 또는 전체 플랫폼 수락 증거는 아닙니다.
