# session-peer v0.9.0

선택형 Antigravity 전달 및 페어링된 기기 릴레이 베타가 추가되었으며, 기존 Claude/Codex 로컬 및 SSH 경로는 그대로 유지됩니다.

- 에이전트 어댑터 및 로컬/SSH 트랜스포트가 이제 명시적인 신원, 기능, 실행 및 구조화된 오류 계약을 공유합니다(#47).
- Antigravity는 인증된 기존 TUI 내에서 시작된 선택형 브리지를 통해 수신할 수 있습니다. 등록은 홈, 프로세스 세대 및 스레드를 바인딩하며, 만료 시간과 요청 한도가 각 브리지를 제한합니다(#85).
- `session-peer[relay]`는 기기 페어링, 직접 TCP 또는 WSS 상의 고정된 내부 TLS 1.3, 피어 철회, 정책으로 제한된 네이티브 대상, 영구 요청 영수증, 목록 조회/전송을 위한 `--device` 연동을 추가합니다(#69).
- 릴레이 입장은 기기 페어링 및 네이티브 승인과 분리되어 있습니다. Linux DynamicUser 배포 예제와 설치/정리 런북이 포함되어 있습니다.
- 페어링된 `--dry-run`은 메시지를 제출하지 않고 대상을 확인합니다. 경로 변경 시에도 고정된 피어와 영수증 저널은 유지됩니다. 알 수 없는 결과는 자동으로 재전송하지 말고 조정해야 합니다.
- 간결한 README가 영어, 한국어, 일본어, 중국어 간체로 제공되며, 각 언어별 빠른 시작 및 선택형 기능 요구 사항이 일치합니다(#92). 전체 CLI 가이드는 `docs/cli-reference.md`에 보존됩니다. 상세 기술 문서는 영어로 유지되며 CLI 출력은 현지화되지 않습니다.
- 공개 버그/기능 템플릿과 비공개 보안 보고 지침이 이제 제공되며, 대체 비공개 연락처로 `support@abruption.dev`를 사용할 수 있습니다(#91). 이메일은 수동으로 검토되며 이슈로 자동 게시되지 않습니다.

## 설치 및 호환성

핵심 기능은 런타임 의존성 없이 여전히 Python 3.9+를 지원합니다. 선택형 릴레이는 Unix 및 Python 3.11+가 필요합니다: `pipx install 'session-peer[relay]'`. 기존 패키지 관리 사용자는 패키지 관리자를 통해 업그레이드해야 합니다. 독립형 `install.sh`는 선택형 릴레이 패키지를 설치하지 않습니다.

Antigravity는 선택 사항입니다. 기본 목록 조회에는 Claude, Codex 및 실행 중인 등록된 Antigravity 브리지가 포함됩니다. 페어링된 네이티브 접근은 수신 기기의 명시적 정책이 필요하며, 페어링 자체로는 네이티브 접근 권한이 부여되지 않습니다. 기기 관리 명령은 JSON을 출력합니다.

## 검증 및 제한 사항

사용자가 승인한 임시 공개 Cloudflare/Caddy WSS 파일럿을 통해 기존 KR Antigravity 세션으로 전달되었으며, 독립적으로 관찰된 모델 ACK 및 중복 요청 시 영수증 재사용이 확인되었습니다. 경로, 서비스, 브리지 및 테스트 키는 이후 제거되었으며, 사용자의 TUI는 계속 실행 상태를 유지했습니다. 이는 제한된 실시간 Antigravity 근거이며, 실시간 Claude/Codex 또는 장기 안정성 근거는 아닙니다.

전송 결과는 제출됨과 소비됨을 구분합니다. 지속되는 의도 저널은 자동 중복 시도를 방지하지만 정확히 한 번 효과를 약속하지는 않습니다. 비정상 종료 시 결과가 알 수 없음으로 남을 수 있습니다. 베타 버전에는 호스팅된 릴레이, 자동 NAT 통과, 자동 키 순환, 저널 가비지 컬렉션 또는 페어링된 wake/Reply-To 라우팅이 없습니다. 운영 제한 사항은 `docs/paired-devices.md`를 참조하십시오.

v1.0.0-rc 전까지 실제 기기 운영 및 결함 해결이 여전히 필요합니다. 이번 릴리스에서는 v1 안정성에 대한 어떠한 주장도 하지 않습니다.
