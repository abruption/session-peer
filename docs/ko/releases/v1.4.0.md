# v1.4.0 릴리스 준비

공개된 v1.3.3을 기준으로 2026-11-02에 준비했습니다. 이 날짜의 점검 시점에서 v1.4.0은 미공개 소스 후보입니다. 통합 기준은 버전 준비 이전의 `f290973962c63548f24153eeee12a8e3666fd043`이며 최종 릴리스 커밋이 아닙니다. 이 준비는 병합, 태그·초안 생성, 워크플로 실행, 공개나 운영 배포를 승인하지 않습니다.

코어 Python 3.9, MCP Python 3.10+와 SDK 요건 `mcp>=1.30,<2`는 변경하지 않습니다.

## 변경 사항

- #356 / #361: 정책에서 파생한 메타데이터만 반환하는 MCP `list_destinations`를 추가합니다. 별칭은 최대 64개, 각 별칭은 UTF-8 128바이트, 도구 결과는 JSON-RPC 외피를 제외하고 64 KiB로 제한합니다. 이 메타데이터 조회는 정책 버전 1과 기본 정책에서도 동작하며 정책 버전 2를 요구하지 않습니다. list/Send 권한으로 필터링하지 않고 설정된 모든 정책 항목을 투영합니다.
- #357 / #362: 단일 대상 CLI `--dry-run --explain-json` 전달 설명을 추가합니다. 기존 출력 형태로 가공하기 전에 원시 SSH 사실을 수집하며 기존 텍스트·JSON 출력 계약을 유지합니다. MCP `preflight_send`에는 정책 버전 2의 별도 `preflight` 권한이 필요하며 preflight가 Send를 암묵적으로 허용하지 않습니다. Wake preflight에는 별도의 wake 권한도 필요하며 모델을 시작하거나 wake 예산을 예약하지 않습니다.
- #358 / #363: 기본 모드에서 `diagnostics` 권한이 필요한 메타데이터 전용 진단을 추가합니다. 능동 프로브에는 추가로 `diagnostics_probe`가 필요하고 Mac/Linux만 지원합니다. 정리를 제외한 실행 한도는 에이전트 3개와 20초이며 각 파이프와 결과는 64 KiB로 제한합니다. 비차단 리더가 프로세스 범위를 벗어난 파이프 보유자를 처리하며 정리 중에도 취소가 우선합니다.
- doctor에서 선택한 에이전트·home이 실제 수집 범위를 정하며 공유 스킬 스캔은 생략합니다. OK 결과는 수집 성공을 뜻하며 에이전트 가용성, DB 증명이나 역방향 프로브를 뜻하지 않습니다.
- #359 / #364: 승인된 이름과 동작별 정확한 경로를 사용하는 정책 버전 2 경로 프리셋을 추가합니다. 어떤 Native 호출보다도 먼저 두 검사를 모두 완료합니다. 경로를 먼저 확인하고 리비전을 다음으로 확인합니다. 실제 전송에는 명시적인 수신 대상과 리비전이 필요합니다. 단일 스냅샷과 그 `dp1` 지문은 대상 식별자나 ACK가 아닙니다. 기존 list/send JSON은 유지하며 안전한 조회 경로에서 복구 동작으로 대체하지 않습니다. 프리셋은 Mac/Linux의 로컬·SSH Claude Code와 Codex 경로로 제한하며 wake, URI, Antigravity, device, handoff와 Windows 지원을 확장하지 않습니다.
- 릴리스 준비에서는 고정된 `send.preflight` 스키마에 없는 일반 네이티브 프로토콜의 응답 루트 필드(`submitted`, `consumptionConfirmed`, `status`, `dryRun`, `queueId`)도 MCP preflight에서 방어적으로 거부합니다. 정상 운영 CLI의 반례, 잘못된 라우팅이나 보안 사고가 관찰된 것은 아닙니다. 이 방어 검사는 기능·프로토콜·ACK·권한을 추가하지 않습니다. 내부 MCP 프로세스 헬퍼는 이제 명시적으로 전달된 시간 제한을 따르며 기본 130초 `CLI_TIMEOUT` 동작은 유지합니다. 이 수정은 현재 정상 호출자에 대한 영향이나 장애가 있었다고 주장하지 않습니다.

## 독립 스킬 호환성

기존 호환 사본과 향후 `SKILL.md` 지원 자산은 별도로 공개된 [Python 스킬 v0.4.1](https://github.com/abruption/session-peer-skill/releases/tag/v0.4.1)을 유지합니다. 소스는 `263b0c333d539dc4e885b16ae3369a26f33097d8`, UTF-8 27126바이트, SHA-256 `fdf5697c04f4a37194986622afb3a7966bb02631c128cf18a323e3fbe5ae90ed`입니다. 최소 런타임 0.9.1, 문서상 전체 지원 범위 1.3.2와 수신기 `codexBin` 하한 1.0.1은 변경하지 않습니다. 지원 사본은 wheel/sdist 밖에 둡니다.

별도 스킬 0.5.0 제안은 최소 0.9.1을 유지하고 실제 런타임 공개와 별도 승인 이후에만 전체 지원 범위를 1.4.0으로 문서화합니다. 후속 스냅샷 PR에서 정확한 스킬 태그·소스·해시를 검증해야 합니다. 미래 태그가 없다는 이유로 이 런타임 준비를 막지 않으며 변경된 바이트를 스킬 0.4.1로 다시 표시해서는 안 됩니다. 이 준비는 제안한 스킬을 공개하거나 설치하지 않습니다.

## 경계와 릴리스 조건

이 확장은 새로운 실제 Native/SSH, Windows 3.14 또는 free-threaded 수락, ACK·중복 제거·handoff 보장, 소유 app-server 지원이나 지원 수준 승격을 추가하지 않습니다. 알 수 없는 역할과 결과의 제한은 유지합니다. 큐 제출은 ACK가 아니며 불확실성은 자동 재시도를 허용하지 않습니다.

정확한 현재 커밋을 리뷰하고 현재 커밋 검사와 최종 보호된 main CI의 성공을 요구하며 공개된 v1.3.3 태그·자산·과거 기록을 모두 보존합니다. 공개를 미리 선언하지 않는 이 날짜별 안내를 고정합니다. 별도 승인된 공개에서는 `SHA256SUMS`, `release-provenance.json`을 포함한 고정 자산 7개를 정확한 태그·소스 및 인증된 attestation과 대조하고 의존성 감사와 새 환경 설치 검사를 수행하며 필수 PyPI 환경의 사람 승인을 유지해야 합니다. 비공개 PyPI 로그인·연결 재확인 생략은 이 승인을 면제하지 않습니다.

제공 여부 안내를 갱신하기 전에 실제 GitHub·PyPI 공개 근거를 별도로 기록하고 미래 공개를 선언하지 않습니다. Python 공개, 전역 MCP 환경 갱신, 서비스 변경, Node Control 배포와 별도로 설치된 스킬은 각각 별도 승인이 필요한 작업입니다.
