# v1.3.1 유지보수 릴리스

공개된 v1.3.0을 기준으로 2026-10-27에 준비했습니다. 이 문서는 소스 변경 범위를 설명합니다. 실제 공개 기록은 [GitHub Releases](https://github.com/abruption/session-peer/releases)와 [PyPI](https://pypi.org/project/session-peer/)에서 확인하십시오.

- #338 / #339: Node Control의 간접 의존성인 Zod를 4.6.5에서 4.6.7로 갱신합니다. [GHSA-mrhx-c7xc-m3w5](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5)는 4.6.6 미만 버전에 해당합니다. 직접 의존성과 감사 정책은 그대로입니다. 고정된 의존성의 보안 경고에 대응하는 수정이며, 운영 중인 엔드포인트에서 악용 가능한지는 평가하거나 재현하지 않았습니다.
- #334 / #335: 별도 스킬 저장소의 소스 `176dc0dab619f074dbfc94de7e01f9a02a052f79`에서 가져온 호환 스킬 v0.4.0을 바이트 변경 없이 포함합니다. SHA-256은 `debedd472e3b0c0c6844fb63f7fb2f17cb6c6cc8c3e981e9afd2531a35327af7`입니다. 최소 런타임은 0.9.1, 문서의 CLI 기능 기준은 1.3.0이며, 수신 측 `codexBin`의 최소 버전은 여전히 1.0.1입니다. 독립 실행형 릴리스의 스킬 자산은 별도로 관리되는 스킬 설치본을 갱신하지 않습니다.
- #336 / #337: 네 언어 README에 PyPI 누적 다운로드 수를 표시합니다.

Python CLI의 동작·의존성·지원 플랫폼·실험적 handoff 제한은 버전 식별자를 제외하면 v1.3.0과 같습니다. Node Control 소스는 Python wheel과 sdist에 포함되지 않습니다. Python 패키지를 발행하거나 설치해도 실행 중인 Control 서비스에는 수정이 적용되지 않습니다. Node 수정 적용에는 별도로 승인된 Control 소스·의존성 갱신과 재시작이 필요합니다.

의존성 수정의 로컬 검증: 새 npm 설치, 타입 검사·빌드, Control 테스트 123개, Node/Python 루프백 연동 테스트 11개가 통과했고 런타임·전체 npm 감사에서 보고된 취약점은 0건입니다. 이는 시험 환경의 결과이며 실제 OAuth·네이티브 에이전트·운영 서비스 검증은 아닙니다. 발행 전에 최종 PR 리뷰, 보호된 main의 CI, 의존성 감사, 재현 가능한 산출물과 신규 설치 검증을 완료해야 합니다.

새 v1.3.1 태그와 검증된 불변 자산을 사용합니다. 기존 v1.3.0 자산은 유지합니다. 네이티브 세대 식별·handoff·저장소·시작 시점 수락 조건(#180/#181/#268/#304/#306/#307)과 Side Session·steering 연구는 별도 과제입니다. 전송 결과가 unknown이면 자동 재전송을 허용하지 않습니다.
