# v1.3.3 유지보수 준비

공개된 v1.3.2를 기준으로 2026-10-30에 준비했습니다. 해당 준비 시점에 v1.3.3은 미공개 후보였습니다. 통합 소스 기준은 버전 준비 이전의 `ec2f7fc808f1e22519348091d51c28a2fd522caf`이며 최종 릴리스 커밋이 아닙니다. 이번 작업은 검토 가능한 변경을 준비할 뿐 병합·태그 생성·발행을 승인하지 않습니다.

## 변경 사항

- #349 / #352: PR 템플릿의 기본 이슈 참조를 종료하지 않는 `Refs`로 바꾸고, 의도적인 완료 표시와 관련 검증·버전 근거를 명시하도록 정리합니다. 읽기 전용 경고는 신뢰된 main의 코드와 제한된 PR 본문 판별 규칙을 사용합니다. 본문을 실행하거나 이슈 상태를 쓰지 않으며, GitHub의 전체 종료 참조 파서나 이슈 종료 방지 보장이 아닙니다.
- #350 / #353: Ubuntu/macOS의 일반 GIL 활성 CPython 3.14 CI를 확장합니다. 코어는 Ubuntu/macOS의 3.9/3.13/3.14와 Windows 3.13을 검증합니다. MCP는 3.10/3.13/3.14의 SDK 하한 1.30.0·최신 호환 1.x 프로필 12개 셀, Relay는 3.11/3.13/3.14의 6개 셀을 검증합니다. 패키지·설치 셀 3개는 Ubuntu 3.13, Ubuntu 3.14, macOS 3.14입니다. 분류자에 3.14를 포함하며 Python 하한은 코어 3.9, MCP 3.10, Relay 3.11로 유지합니다. [소스 시험 행렬](https://github.com/abruption/session-peer/blob/ec2f7fc808f1e22519348091d51c28a2fd522caf/tests/README.md)을 참고하십시오.
- #351 / #354: 현재 README의 공개 안내를 특정 최신 버전에 고정하지 않도록 정리하고, 별도의 날짜별 v1.3.2 공개 기록을 추가합니다. 과거 준비 기록은 보존하고 기존 공개 후 점검표를 명확히 하며, 네 언어 Direct 가이드의 오래된 미공개 표기를 바로잡습니다.
- 호환 사본과 향후 `SKILL.md` 지원 자산을 독립적으로 공개된 [Python 스킬 v0.4.1](https://github.com/abruption/session-peer-skill/releases/tag/v0.4.1)에 맞춥니다. 이는 호환 사본 갱신이며 새 스킬 발행이나 별도 설치된 스킬의 갱신이 아닙니다.

## 정확한 소스와 호환성

병합된 소스는 #352 `6f9026e46138db544fb9c990387fcd4ccf37400f`, #353 `88f2c906e3f4bae8b377fcfac049a65fd68dea64`, #354 `ec2f7fc808f1e22519348091d51c28a2fd522caf`입니다.

스킬 사본은 `abruption/session-peer-skill` 저장소의 `v0.4.1` 태그에 해당하는 커밋 `263b0c333d539dc4e885b16ae3369a26f33097d8`에서 가져왔으며, annotated 태그 객체는 `ba08d19af33cad0f7d032b7fe18c82d6ddd6793f`입니다. UTF-8 27126바이트이며 SHA-256은 `fdf5697c04f4a37194986622afb3a7966bb02631c128cf18a323e3fbe5ae90ed`입니다. 스킬 버전은 0.4.1, 기본 런타임 하한은 0.9.1, 문서의 CLI 기능 범위 기준은 1.3.2, 수신기 `codexBin` 하한은 1.0.1입니다. 이 숫자는 런타임 1.3.3과 독립적입니다. 지원 사본은 Python wheel/sdist에 포함되지 않습니다.

## 범위와 릴리스 게이트

3.14 검사는 전용 테스트 구성(fixture) 기반 시험과 패키지 검증이며, 실제 네이티브 에이전트·Windows 3.14·free-threaded Python을 새로 수락 검증한 것은 아닙니다. 버전 상향과 문서 변경은 런타임 인증·프로토콜·전달·ACK 동작을 추가하지 않습니다. 불확실한 결과의 처리, 자동 재전송 금지와 실험적 기능의 기존 범위는 유지합니다.

위 통합 소스 기준의 [CI](https://github.com/abruption/session-peer/actions/runs/40982760413)와 [CodeQL](https://github.com/abruption/session-peer/actions/runs/40982759604)은 성공했습니다. 이 결과는 준비 커밋이나 최종 보호된 main 소스의 검사를 대신하지 않습니다. 먼저 [첫 CI](https://github.com/abruption/session-peer/actions/runs/40880779432)에서 신규 3.14 셀 10개가 통과한 뒤 분류자를 추가했고, 이후 [갱신된 전체 CI](https://github.com/abruption/session-peer/actions/runs/40882642483)도 통과했습니다.

공개된 v1.3.2의 태그·자산과 날짜별 기록은 그대로 보존합니다. 정확한 준비 커밋을 검토하고 해당 커밋의 검사를 통과한 뒤, 이후 릴리스 단계 전에 보호된 main의 CI 성공도 확인해야 합니다. 별도로 승인된 발행에서는 `SHA256SUMS`, `release-provenance.json`을 포함한 고정 자산 7개를 정확한 태그·소스 및 인증된 attestation과 대조하고, 새 환경 설치를 시험하며 필수 PyPI 환경의 사람 승인을 유지해야 합니다. 비공개 PyPI 로그인·연결 재확인 생략은 이 승인을 면제하지 않습니다. 실제 GitHub·PyPI 근거를 확보한 뒤 기존 공개 후 문서 점검표를 사용하고 제공 여부를 미리 선언하지 마십시오.

이 준비는 서비스 배포·재시작, 전역 설치나 독립 스킬 발행을 수행하지 않습니다. Node Control 배포와 수신기·스킬 환경 갱신은 별도로 승인된 운영 작업입니다.
